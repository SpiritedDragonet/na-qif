# 致谢导师表述对齐设计

本次修改只处理 `back/acknowledgements.tex`。目标是让致谢中的导师表述与论文书面导师信息对齐，同时尽量保持当前致谢的主体结构、情感重心和语言风格不变。

具体做法是，在致谢开头新增一个很短的自然段，用于感谢任晶老师在研究生阶段的指导、关心与支持，并补入其在论文推进不顺时给予安慰和鼓励这一真实经历。该段不解释两位老师之间的分工，不使用可能引发额外联想的表述。

原先围绕刘哲老师展开的第一段仅轻改首句，将“最想感谢的人是我的导师刘哲老师”改为不带排他色彩的表达，使其能够顺畅承接前一段。除这两处外，其余段落内容和顺序保持不变。

修改完成后的成功标准是：读者先看导师栏，再看致谢，不会感到前后失配；任晶老师出现的位置足够郑重，但不会挤占刘哲老师相关段落的主体分量；整篇致谢仍然保留当前版本的真实感和连贯性。
