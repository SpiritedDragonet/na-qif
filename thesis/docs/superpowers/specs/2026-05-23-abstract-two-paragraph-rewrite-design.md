# 摘要两段式重写设计

本次修改面向评审老师对摘要观感和组织方式的意见。当前中文摘要和英文摘要都集中为一个长段，信息密度高，读者需要在同一段中同时识别研究背景、方法框架、数值实现和结果结论。修改目标是把摘要改为国内研究生论文中更常见的两段式结构，使第一段负责说明研究意义、领域痛点和研究对象，第二段负责说明具体工作、主要结果和结论。修改应降低自夸语气，保留可核验的技术内容和结果数值。

第一段采用“领域需求—问题痛点—研究对象—解决路径”的顺序。段落开头说明量子网络与分布式量子计算需要稳定建立远程纠缠资源，随后指出中性原子光子--原子接口链路中存在损耗、模式失配、频率转换噪声、探测背景和暗计数等耦合非理想因素。段落结尾收束到论文的研究目标，即围绕具有代表性的中性原子接口链路，建立能够追溯误差来源并支持参数比较的链路仿真与误差预算方法。该段不使用夸大价值的表述，重点让读者理解研究为什么需要做。

第二段采用“首先—其次—进一步—结果表明”的自然顺序。首先说明基于时间分箱离散化、MPS 张量网络和 TEBD 构建原子发射、QFC、光纤传播、BSM 和探测器响应的统一演化与条件化测量模型。其次说明通过量子轨迹采样、Kraus 算符投影和成功探测记录集合重建原子约化密度矩阵，并计算成功率、真/假成功分量、条件保真度和 CHSH 指标。进一步说明研究进行了参数锚定、窗口扫描、HOM 干涉拟合、QFC/探测参数工作平面和距离扩展分析。结果部分保留强具体信息，包括 70 ns 数据接收窗口、约 0.75 rad 的分束器推荐工作点、假成功中背景辅助约 58.7% 且暗计数辅助约 41.3%、小时间差区域承载更高比例真成功、长链路下成功率先退化而保真度退化相对滞后，以及代表性运行中探测阶段占总耗时 99.42%。这些数值用于支撑结论，不能被写成宣传式亮点。

中文摘要和英文摘要需要同步重写，逻辑结构保持一致。英文摘要可以保留学术英文的自然句法，不必逐句硬译中文，但需要对应同一组研究对象、方法步骤和结果结论。关键词同步压缩为五个，建议中文为“量子接口、中性原子、远程纠缠、矩阵乘积态、量子频率转换”，英文为“Quantum interface, Neutral atom, Remote entanglement, Matrix product state, Quantum frequency conversion”。现有关键词中的“量子网络”和“时间分箱离散化”可以由摘要正文承担，不再占用关键词位置。

修改完成后需要重新编译或至少运行不写 PDF 的 XeLaTeX 验证摘要环境、关键词解析和引用状态不受影响。由于当前 `thesis.pdf` 可能被阅读器占用，若正常写 PDF 失败，应先用 `xelatex -no-pdf` 验证 TeX 结构，再在 PDF 释放后覆盖主 PDF。最终还需要检查 `front/cover.tex` 中中文摘要、英文摘要和关键词数量是否一致，避免中英文摘要结构不对应。
