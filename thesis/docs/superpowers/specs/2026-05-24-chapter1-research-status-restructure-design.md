# 第一章研究现状结构调整设计

本次修改面向第一章目录结构与评审可读性问题。当前第一章已经包含较多与国内外研究现状相关的内容，但这些内容的章节归属不够直观。`1.2 国内外研究现状` 目前只有一段总述，容易让评审在扫目录和快速浏览时形成“研究现状太少、太笼统”的第一印象；后续 `1.3 中性原子量子接口链路` 和 `1.4 链路级性能瓶颈分析` 实际上承担了代表性实验路线、链路选型依据、性能瓶颈和建模需求的研究现状展开，却被标题包装成了“本文对象说明”和“性能分析”。修改目标是让目录层级直接呈现“研究背景、国内外研究现状、存在问题、本文研究内容”的常见阅读路径，同时保留当前正文中已经较具体的实验链路、参数依据、图表说明和文献支撑。

本次修改不做整章重写。第一原则是迁移和归并现有内容，第二原则是只在段落首尾、节间过渡和问题收束处做必要改写，第三原则是通过与基线 commit `6a71ea45` 的 diff 对比检查细节是否被删薄。当前版本已经在 `6a71ea45 Save thesis review revision baseline` 中提交，后续调整完成后必须以该 commit 为原版，逐项核对原有 `1.3` 和 `1.4` 的具体信息是否仍能在新版本中找到对应表述。

### 标题策略

标题应采用功能清楚、对象具体的写法。一级标题可以符合国内硕士论文常见结构，但二级标题必须落到具体技术对象上。避免连续使用为了对仗而形成的 `xxx 与 xxx` 标题，也避免过于空泛的 `研究背景及意义`、`量子接口研究现状`、`现有研究存在的问题` 这类标题。标题的作用是让评审快速识别这一节讨论的是哪一类文献、哪一条技术路线或哪一个具体问题。

建议结构如下。

```tex
\section{量子计算研究背景}
\subsection{量子计算基本概念与模型}
\subsection{量子计算的工程化应用}
\subsection{可扩展量子计算体系结构需求}

\section{国内外研究现状}
\subsection{可扩展量子计算体系结构研究进展}
\subsection{量子接口平台研究进展}
\subsection{中性原子处理节点研究进展}
\subsection{长距离原子--光子纠缠链路研究进展}
\subsection{链路性能建模研究进展}

\section{本文研究内容}
\subsection{研究对象}
\subsection{建模方法}
\subsection{章节安排}
```

这套结构介于中等调整和整章重构之间。它会显著改变目录阅读效果，但不把第一章技术细节重新生成一遍。现有 `1.1` 的基本概念、工程化应用和体系结构压力可以保留在新的背景部分。现有 `1.2` 的总述段落应拆分并扩展为 `国内外研究现状` 的导入和各小节过渡。现有 `1.3` 的主体应迁入 `中性原子处理节点研究进展` 与 `长距离原子--光子纠缠链路研究进展`。现有 `1.4` 的主体应迁入 `链路性能建模研究进展`，并在末尾明确落到本文建模需求。现有 `1.5` 的方法概述和章节安排应改为新的 `本文研究内容`。

### 内容迁移方案

绪论开头第 5 行的长段已经承担总背景功能，可以保留在章节开头，也可以在不改变信息量的前提下略作拆分。该段中的量子计算意义、量子接口重要性、中性原子节点代表性和远程纠缠链路边界不能删掉。后续如果需要压缩，应优先压缩重复表述，而不是删除“量子接口直接影响远程纠缠建立速率、成功率与条件态质量”这一主线句。

当前 `1.1 量子计算简介` 应改为 `量子计算研究背景`。`量子计算基本概念与模型` 可以基本保留，只需检查 DOCOMO 替换后的退火/QUBO 引用是否语义自然。`工程化价值与应用牵引` 可以改为 `量子计算的工程化应用`，保留无线网络优化和燃料隔离带两个例子。`可扩展性压力与模块化思路` 可以改为 `可扩展量子计算体系结构需求`，保留图 `fig_ch1_system_pressure`、图 `fig_ch1_modular_network`、接口 primitive 表和平台比较表。这一部分更像背景与问题引入，不应并入研究现状的主体，以免 `国内外研究现状` 过长且前后重复。

当前 `1.2 国内外研究现状` 的一大段应重写为新 `1.2` 的导入与前两个小节。第一部分聚焦可扩展量子计算体系结构，沿控制扇出、低温读出、串扰标定、实时译码、闭环维护、逻辑纠错运行和模块化互连展开。第二部分聚焦量子接口平台，承接接口 primitive 和平台比较表，说明不同平台在存储、中继、本地处理和光子接口能力上的差异。这里需要保留国际研究与国内研究的代表性文献，而不是只写综述性判断。

当前 `1.3 中性原子量子接口链路` 的第一大段应迁入 `1.2.3 中性原子处理节点研究进展`。该段中的中性原子节点定义、通信比特和计算比特分工、处理中性原子节点与模块化量子计算的关系、光镊阵列与腔/波导接口潜力等内容都需要保留。`$^{87}$Rb + 高精细度光学腔 + QFC + 电信光纤 + 中继站 BSM` 的链路组合可以在本节末尾引出，但不要把它写成本文的孤立选择，而应写成已有实验路线中具有代表性的链路对象。

当前 `1.3` 中关于 $^{87}$Rb、腔增强、QFC、$1517\,\mathrm{nm}$、两臂约 $16\,\mathrm{km}$ 光纤、经典通信时延、双光子干涉和部分 BSM 的详细论证，应迁入 `1.2.4 长距离原子--光子纠缠链路研究进展`。这些细节是当前第一章最具体的研究现状材料之一，不能在改写中压成一句“该链路具有代表性”。图 `fig_link_overview` 也应保留在这一节或紧随其后，图题中对节点 A/B、QFC、$L_1,L_2\le 16.5\,\mathrm{km}$、BSM、PPLN、SNSPD 等要素的解释应保留。

当前 `1.4 链路级性能瓶颈分析` 应迁入 `1.2.5 链路性能建模研究进展`。`成功率与距离代价` 的内容用于说明宣告成功率的乘法塌缩、光纤损耗、等待宣告导致的尝试频率限制和相干寿命压力。`保真度退化与噪声受限机制` 的内容用于说明不可区分性、模式失配、暗计数、QFC 背景、假宣告、噪声受限区间、时间窗和滤波记忆。这些段落应保留主要技术链条，并在末尾增加一到两句研究问题收束，说明仅靠效率相乘或单个有效可见度难以解释多源噪声和条件化测量的统计后果，因此需要统一时间域链路模型。

当前 `1.5 主要研究内容与结构安排` 应改为 `本文研究内容`。`链路建模方法概述` 中的时间分箱、MPS、TEBD、POVM 和条件化测量内容可作为 `建模方法` 小节保留。`研究内容与章节安排` 应拆成 `研究对象` 与 `章节安排` 两段或两个小节。`研究对象` 只写本文明确处理的链路、指标和边界，避免重复前面研究现状中的大段文献综述。`章节安排` 保持简明，说明第二章理论方法、第三章模型、第四章数值结果与误差预算。

### 改写边界

正文调整时不得把当前 `1.3` 和 `1.4` 整段删除后重新生成摘要式版本。可以移动段落、拆分长段、改写首句和末句，也可以删除明显重复的承接句。对于包含具体实验对象、波长、距离、器件和噪声机制的句子，应优先保留原句或在同等信息量下改写。图表的 label、引用和正文指代需要随章节移动保持一致。

参考文献不应因为结构调整而被大幅替换。若只是迁移段落，原引用应随段落保留。只有当某个段落的语义发生变化时，才重新检查引用是否合适。已经完成的 DOCOMO 日文网页替换不应回退。

正文改写必须遵循项目 `AGENTS.md` 的写作风格约定。输出应采用清晰、流畅的散文，以完整段落组织逻辑，避免把论文正文写成项目符号式清单。除非内容天然是彼此独立的项目，否则不使用有序或无序列表。标题和正文中不使用加粗、斜体等多余格式。每句话都应能独立成立，避免通过否定另一个说法来支撑本句观点。涉及研究背景、研究现状和问题总结时，应让要点自然融入段落推进，而不是堆叠短句或模板化标签。
