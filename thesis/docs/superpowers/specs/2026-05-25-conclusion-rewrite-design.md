# 结论部分分条重写设计

## 背景

内审意见指出，结论部分需要把研究结果的意义说明白，并以更清晰的分条方式呈现主要结论。当前 `back/conclusion.tex` 基本是一整段长段落，信息量充足，但阅读路径不够清楚。由于前文已经出现过图题、图注和研究归属容易被误读的问题，结论部分还需要让评审自然看出核心判断来自本研究的链路级仿真、参数扫描和误差预算，而不是来自文献搬运。

## 重写目标

结论部分应具有结论的样子，重点回答研究得到了什么判断、这些判断说明什么，以及它们对后续实验调参和链路评估有什么意义。重写时不把第三章的方法细节或第四章的作图组织重新讲一遍，方法只作为结果来源被轻带过。公开实验数据只作为基线锚点或对照点出现，用来说明参数来源和结果对照关系。

## 结构设计

结论采用“开头小段 + 三条编号结论 + 收束小段”的结构。开头小段简要交代研究对象和结论范围，避免展开建模过程。中间三条用“第一，……”“第二，……”“第三，……”的形式呈现，但每一条写成完整论文段落，而不是提纲式短句。收束小段说明这些结果对实验闭环标定、窗口选择、器件优化和后续链路扩展分析的价值。

第一条结论聚焦链路评估指标。它应说明链路质量不能只看宣告成功率，而需要同时区分真成功、假成功和条件态质量。这里可以保留真假成功分解、背景辅助和暗计数辅助等关键结果，但重点放在“单一成功率不足以评价链路状态”这一判断。

第二条结论聚焦工作点形成机制。它应说明时间窗口、HOM 干涉质量和 BSM 记录真实性共同决定可用工作点。这里可以保留 70 ns 数据窗口、约 0.75 rad 推荐分束器工作点、58.7% 背景辅助假成功、41.3% 内禀暗计数辅助假成功，以及小时间差区域承载更多真实事件等结果。写法上应把这些数字组织成一个结果判断，而不是重新讲窗口扫描或拟合流程。

第三条结论聚焦长距离扩展和器件参数约束。它应说明长距离传输中可用事件率通常先成为瓶颈，背景噪声和探测效率随后限制条件态质量。这里可以写 QFC 背景、探测效率、距离标度和误差预算给出的调参顺序。重点放在实验优化优先级：先保证源端波包和 HOM 稳定，再确定窗口与探测工作点，最后核查 Bell 态质量和更高目标保真度下的相位、频域噪声。

## 语言约束

重写应遵循 `AGENTS.md` 的散文化写作风格。虽然结论采用编号陈述，但每条仍应是完整、连贯的段落。避免把信息拆成二级项目符号，也避免短句堆叠。少用“本文”，只在开头或确有必要处使用。不要反复写“本文完成了”“本文提出了”来强调工作量。工作归属应通过具体结论、具体指标和具体对照关系自然体现。

表述应避免生硬的自夸和防御性解释。对于公开实验数据，使用“公开实验参数作为基线锚点”“公开实验结果作为对照点”这类说法，不在结论里制造“这是不是我做的”的疑问。对于研究意义，使用“为……提供依据”“有助于……判断”“可作为……参考”等克制表达。

## 验收标准

重写后的结论应比当前版本更容易扫读。评审应能快速看到三条主要结论，每条结论都包含结果判断、关键数据和实验意义。全文不应显得像方法回顾，也不应显得像在反复声明工作归属。编译后不应引入未定义引用、标签错误或明显格式问题。
