## 我对你当前仿真链路的复盘（按代码实际做了什么）

### 1) 发射（MPS+TEBD/碰撞模型）

- 链布局：`A1,B1,...,AN,BN,atomA,atomB`，先把 `BN <-> atomA` 交换，然后每个 time bin 上对 atomA 与 A_n、atomB 与 B_n 施加同一个 `emission_gate`，再把原子往左 swap，最终得到 `atomA,atomB,A1,B1,...,AN,BN`。
- `emission_gate` 的生成器形式：
  (U = \exp{\sqrt{\Delta t}(L\otimes b^\dagger - L^\dagger\otimes b) - i\Delta t (H_{sys}\otimes I)})，其中 (L_H,L_V) 由 (S_+=|0\rangle\langle e|,,S_- = |1\rangle\langle e|) 和 `Alpha` 矩阵组合。
- 这相当于“系统与每个时间片真空浴模式做一次 collision”，是合理的连续输出场离散化思路。

### 2) QFC + 780 过滤 + 投影到 1517

- `apply_qfc` 对每个 bin 施加一个 18×18 的 unitary，把 780 与 1517 做类 beamsplitter 混合：(\theta_H,\theta_V) 控制转换概率。
- 然后 `apply_780_filter` 用 `loss_channel_both_subspaces(eta_780=0)` 得到一组 Kraus，但**只取第 0 个 Kraus**（相当于“后选 780 子空间已经是 vacuum 的分支”），并把这个分支概率积起来当作 `p_no_loss_780`。
- `project_to_1517` 假设 780 子空间已经真空，于是把 18 维物理腿直接压到 6 维（只保留 780=vac 的那 6 个分量）。

### 3) 光纤：偏振随机、相位漂移/斜率、PDL、损耗

- 偏振：对每个 bin 的 A、B 分别施加 `jones_gate(U_A)`、`jones_gate(U_B)`。其中 B 还带一个全局相位 `exp(i phase)`，并可叠加每个 bin 的线性相位斜率和 jitter（phase profile）。
- 损耗：`loss_channel_1517_raw` 得到 Kraus 列表，但同样 **只取第 0 个 Kraus（no-loss 分支）**，对所有 bins 固定施加，然后把该分支概率积起来当 `p_no_loss_fiber`。

### 4) 原子退相干

- 用随机 Z（I / Z）来做纯退相干，等待时间 `t_wait_us` → (p=(1-e^{-t/T_2})/2)。实现里 Z 对 4D 原子空间是 diag([1,-1,1,1])，这点是对的（CPTP）。

### 5) 中间站 BS

- 对每个 time bin 的 (A_n,B_n) 施加 36×36 的 `bs_gate_6d`（分别对 H/V 做 beamsplitter）。

### 6) 探测与“Bell 态投影/保真度”

- `run_detection_pipeline` 在 6D 基里构造每个端口的桶式探测 POVM（含效率 η_det + 暗计数 p_dark），再做二端口张量得到 36D 的“每个 bin 的 click pattern effect”。
- 然后用 MPO/环境张量，枚举两次点击(2-click)记录的总概率、以及成功模式（Ψ± 的那四种 detector pair）的概率与对应 Bell fidelity。
- `determine_bell_state` 把 {H1,V2}/{V1,H2} 归为 Ψ−，把 {H1,V1}/{H2,V2} 归为 Ψ+。

## P0（必须优先修）会显著影响“对实验有指导意义”的点

### P0-1：你把 **QFC 失败**当成“后选掉”的轨道了（会系统性偏乐观）

（已修）QFC+780 过滤已推入 POVM，不再在态端只取 `K_list[0]` 后选。

这会带来两个很实际的偏差：

1. **成功率/计数率**：旧版曾在“QFC 成功（或至少 780 没残留）”的后选条件下汇报 `p_success_*`。现在已改为输出绝对概率（`p_success_abs` 等），避免误用。
2. **暗计数主导的假成功比例**：实验里 QFC 失败会让 1517 真空分量变大；真空越大，暗计数造成的“看上去是两击成功”的比例越高。
   你现在因为把 QFC 失败的分支直接丢掉了，**会低估暗计数假成功**，从而 **高估 heralded fidelity**（尤其在长距离/低传输时）。

> 直觉总结：
> 你现在的 fidelity 曲线更像“假设只统计到真的两光子事件”的 fidelity，而不是“实验上挑出来的所有‘看似成功事件’的 fidelity”。

------

### P0-2：你把 **光纤损耗**也当成“后选 no-loss”轨道了（同样会低估暗计数假成功，并扭曲距离标度）

（已修）光纤损耗已推入 POVM，不再在态端只施加 no-loss Kraus。

这对“**给实验指导**”影响更大，因为实验里最核心的一个现象是：

- 距离一长，真光子双击事件衰减；
- 暗计数/背景噪声的“碰巧两击”衰减慢得多；
- 所以 heralded fidelity 会明显下滑。

而你当前做法会把“光纤丢光子导致真空增多”这一条路径大部分排除掉，只留下一条“有光子但被衰减系数缩放”的条件轨道，从而 **低估暗计数污染随距离的恶化**。

### P0-3：`p_success_*` 的语义需要拆清楚，避免把条件量当绝对量

### P0-4：你现在的“探测 → 原子后选态”是用 POVM effect 做 Lüders 更新；对桶式探测的 backaction 可能偏理想

`detection.py` 里最终用的是 effect (E) 插入网络来得到原子密度矩阵（相当于 Lüders 规则）。

桶式探测(click)在物理上是“吸收型 + 记录经典结果”，对于把不同 photon-number 过程 coarse-grain 到同一个“click”的情况，真实仪器通常会**更强地破坏相干**。Lüders 更新往往会偏“保留相干”，可能会略高估 heralded entanglement（尤其当你允许 2-photon bunching（|2H>, |HV|）且又不数光子时）。

我不说一定错，但要注意：

- 如果你主要对比实验的 heralded fidelity 曲线，这里可能会变成“系统性偏高一点”的来源之一。
- 想做得更贴近光电探测，可以把“click”建模为更接近 quantum jump 的测量算符（例如与 annihilation operator 相关的 Kraus），而不是仅仅用 (E) 的 Lüders 更新。
  （这点属于“上限更高”的改进，先解决 P0-1/P0-2 更关键。）

## P1：你已经写了，但会让“物理含义/可解释性”打折的地方

### P1-1：QFC 目前是“理想 unitary beamsplitter”，但后面又用“后选”把它变成“有效效率”

`apply_qfc` 用 unitary 混合 780 和 1517，本来是 coherent process；但你随后 `apply_780_filter` 又后选掉 780 非真空分支，等价于“只留下 converted 成功的那部分”。

从“只关心 heralded 的真两光子事件”角度，这没问题；但从“指导实验、看清不同噪声怎么混入”的角度，建议你明确两种模式：

- **模式A（heralded-only, 只研究真正成功事件的“物理极限”）**：允许后选 no-loss/no-780，输出 conditional fidelity；用于研究模式匹配、相位漂移、偏振扰动对“理想成功事件”的影响。
- **模式B（experiment-realistic, 研究实验真实挑出来的成功事件）**：必须包含 QFC 失败与光纤损耗分支，因为它们会把暗计数假成功占比大幅抬高。

你现在的代码更接近模式A，但同时又加入了暗计数并计算 fidelity_false，让人直觉上会以为是在做模式B——这就容易“看起来更真实，实则漏掉最关键的真实影响路径”。

### P1-2：时间 bin 的时间轴定义是“倒序映射”，很容易在分析/画图时搞反

你用 `_bin_to_time_index = (n_bins-1)-bin_index` 把 bin 0 映射到最后时刻。
而链布局最后是 `A1,B1,A2,B2,...` 的正序。这样在画 per_bin_prob 或者把 “delay_ns” 映射到 click bin 分布时，很容易出现“图像沿时间翻转”的隐性错误。

建议：

- 要么统一规定 **bin index 越大时间越晚**（最直观），并把 emission loop/交换顺序调整到一致；
- 要么保持你现在的实现，但所有输出/绘图都用 `time_idx` 统一重排，并在输出里明确标注。

## P1：对实验最“掉保真”的关键因素，你现在还没仿或仿得太理想

下面按“通常在你这种方案里对可见度/保真度影响的优先级”列（我不假设你实验细节，但给出通用建议）：

### 1) 两光子不可区分性（HOM visibility / mode overlap）——你现在只仿了“时间延迟”，还缺“模式不重叠”

你有 delay、delay_jitter、phase_slope/phase_jitter，这能覆盖“到达时间/相位不匹配”。

但现实里最常见的可见度杀手是：

- 谱线不完全一致（中心频率抖动、谱宽差）
- 时间包络不一致（脉冲形状、QFC 带宽/滤波）
- 空间/偏振模式重叠不完美（耦合到单模纤不理想，偏振补偿不完美）

这些往往可以用一个“**有效可见度 V 或 mode-overlap μ**”来建模：把每个光子的模式分成“可干涉部分”和“不可干涉部分”，不可干涉部分在 BS 上当作 distinguishable，从而直接降低 BSM 投影质量与成功分布。
**如果你想让仿真对实验“调参”有指导意义，这一项非常建议加入。**

实现建议（不引入巨大 Hilbert 维度的简化法）：

- 在 BS 前引入一个参数 μ：以概率 μ 走理想干涉，概率 1-μ 走“无干涉”的统计（等价于对 two-photon interference 项做衰减）。
- 更精细一点：把每个 bin 的两光子项按 μ 衰减。

### 2) QFC 噪声光子（尤其是 telecom 端的 Raman/泵噪声）

你现在 QFC 只有“效率/相位”这类理想误差，没有“噪声光子自发产生”。

实验上 QFC 往往会引入：

- 与泵相关的宽带噪声光子（telecom端）
- 这些噪声会显著抬高“假两击成功”的底噪，并强烈依赖滤波带宽和泵功率

如果要做“指导实验”，强烈建议加入：

- 每个 bin、每个端口一个 Poisson/thermal 的“噪声光子注入”模型（至少 0/1 光子），再走同样的 BS+探测。
  这会比你现在仅靠暗计数建模更贴近真实情况（尤其是在长纤+QFC 场景下）。

### 3) 光纤色散/PMD（是否需要看你光子带宽）

16 km 对窄带（MHz 级）光子可能不太严重，但如果你的光子谱宽较大或滤波不够窄，色散会把 time-bin 波包拉宽，改变 bin 间相关并影响干涉窗口。你现在光纤只做了偏振/相位/损耗，没有把波包卷积拉宽。

### 4) 中间站光学器件非理想：BS 不平衡、偏振串扰、路径损耗不对称

你 BS 固定 50/50，且没有器件损耗与偏振串扰。
实验里这会直接影响：

- Ψ± 两类事件的相对出现概率
- 误判/串扰导致的 fidelity 下降

可以先加最简单的：

- BS: θ ≠ π/4
- 在 BS 前后加一个小的 unitary 偏振串扰（Jones not exactly identity）
- 端口损耗不对称

### 5) 探测器更真实的非理想：时间抖动、死时间、afterpulsing、四个通道效率不一致

你现在的探测是 per-bin 独立的 POVM，暗计数是每个 detector 独立 Bernoulli。
这对第一版是够用的，但如果你发现仿真和实验 click-time histogram 的形状对不上，通常就是这些因素在作怪。

## 给你一条“最小改动但显著提升可信度”的路线图

### Step 1：先把输出指标“语义”钉死（避免自己误用）

在 summary 里同时输出：

- `p_success_cond`（当前输出已改名为 `p_success_abs`，为绝对概率）
- `p_no_loss`（你现在已有）
- `p_success_abs_approx = p_no_loss * p_success_cond`（先做近似列出来）

这样至少不会把条件概率当绝对概率。

### Step 2：把“QFC失败/光纤丢光子导致的暗计数假成功”补回来（这是你 fidelity-vs-distance 真实性的关键）

这里有三种实现难度从低到高的方案，你可以选：

**方案B（工程上最稳、但要改 detection）：把损耗/过滤推到 POVM 的对偶映射（Heisenberg picture）**
因为你的 `detection.py` 最终只用 effect (E) 做网络收缩，概率与后选原子态都可以用
[
E_{\rm eff}=\sum_\mu K_\mu^\dagger E K_\mu
]
把信道合并进测量算符，而不需要把态变成 mixed MPS。
这样可以**精确包含丢光子分支**，仍然保持你现在的“枚举+收缩”框架（不走 Monte Carlo）。
这一条在数学上是成立的，且非常适合 MPS（因为你本来就在“对固定 effect 做收缩”）。

实现上你可能要：

- 不在 `trajectory` 里做 loss 的后选（甚至 BS 也可以不作用到态上，而是把 BS 共轭到 effect 上）
- 在 detection 构建 `effects_all` 后，对每个 bin 的 effect 做一次 “channel adjoint” 变换。

**方案A（改动小、但要 Monte Carlo）：loss/filter 用 Kraus 采样而不是固定 no-loss**

- `apply_780_filter`：不要只取 `K_list[0]`；对每个 bin 用 `apply_kraus_one_site` 从 `[K0,K1,K2]` 里采样，保留失败分支（那条分支会把 telecom 变成 vacuum），然后再 `project_to_1517`。
- `apply_fiber_channel`：同理，对每个 bin 用完整 Kraus 采样，而不是固定 no-loss。
  这样你就能在统计上看到“loss 越大 → 暗计数假成功比例越大 → fidelity 掉得越狠”。代价是需要更多 runs 做平均。

**方案C（最快但更近似）：把 fiber loss + detector efficiency 合并成有效 η，同时显式算 0/1/2 光子到达的权重**
这能做一个“快速对照曲线”，但对 BS 前 loss 与干涉的耦合不一定完全等价；适合先 sanity-check，不适合作为最终指导结论。
