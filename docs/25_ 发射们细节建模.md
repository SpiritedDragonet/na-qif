一、你当前 emission 在数学上到底是什么

你现在的 `emission_gate(gamma, dt, Alpha, ...)` 本质是离散 QSDE / collision model 的标准幺正：
[
U_n=\exp\left(\sqrt{\Delta t}\sum_{p\in{H,V}}(L_p\otimes b_{n,p}^\dagger-L_p^\dagger\otimes b_{n,p})\right),
]
其中 (L_H,L_V) 由原子跃迁算符 (S_+=|0\rangle\langle e|)、(S_- = |1\rangle\langle e|) 线性组合得到。你在代码里就是这么写的：先用 `atom_transition('+')/'-'` 构造 (S_\pm)，再按 `Alpha` 拼成 (L_H,L_V)，最后 `expm` 指数化生成幺正门。

`run_dual_atom_emission` 里目前是先在时间网格上人为给一个高斯轮廓 `gamma_A_values/gamma_B_values`，再逐 bin 去调用 `emission_gate`。

你自己也已经意识到核心问题：在这种单激发、马尔可夫建模里，“输出波包强度”一般不是你随手写的 (\gamma(t))，而是类似 (|w(t)|^2=\gamma(t)|c_{\text{exc}}(t)|^2)，而 (c_{\text{exc}}(t)) 又被 (\gamma(t)) 反过来决定，所以直接写个高斯 (\gamma(t)) 通常不会得到高斯输出。

因此，想要“第一性原理地从激发脉冲 (\Omega(t)) 推出输出单光子波包”，正确的工程拆分是：

二、推荐的 emission 设计：两层结构（波包生成器 + gate 编译器）

层 1：物理波包生成器（(\Omega(t)\rightarrow w_0(t)) 或 (\Phi_{\rm out}(t))）

你已经找到的 PRA 方案非常合适：用腔 QED 三能级（(|u\rangle,|e\rangle,|g\rangle)）在单激发子空间的振幅方程正推。核心方程就是（你文档里列的 (4)–(6)）：

[
\dot{\alpha}*u=-i\Delta_u \alpha_u-\Omega^\*(t)\alpha_e,
]
[
\dot{\alpha}\*e=-(\gamma+i\Delta_e)\alpha_e+\Omega(t)\alpha_u+g\alpha_g,
]
[
\dot{\alpha}\*g=-\kappa \alpha_g-g\alpha_e,
]
并且输出到“外耦合通道”的成功通量（或未归一化波包强度）是
[
\Phi\*{\rm out}(t)=2\kappa\*{\rm ex}|\alpha_g(t)|^2,
]
（(\kappa=\kappa*{\rm in}+\kappa_{\rm ex})）。

这一步解决你最在意的“输入激发光调制波形 (\Omega(t)) 怎么决定输出波包形状”的第一性原理链路：你调 (\Omega(t))、(g)、(\kappa_{\rm ex/in})、(\gamma)、失谐，输出 (\alpha_g(t)) 就变，从而 (\Phi_{\rm out}(t)) 就变。

层 2：time-bin gate 编译器（(w_0(t)) 或 (\Phi_{\rm out}(t)\rightarrow) 每个 bin 的发射门强度）

你 MPS/TEBD 这层不需要知道腔里发生了什么，它只需要知道：“第 (n) 个 bin 里应该写入多大幅度（以及什么相位）”。

把连续波包离散到 time bins 的标准做法是：定义 bin 模算符
[
a_n^\dagger=\frac{1}{\sqrt{\Delta t}}\int_{t_n}^{t_{n+1}} b^\dagger(t),dt,
]
则单光子波包的离散幅度可取
[
\xi_n \approx w_0(t_n)\sqrt{\Delta t},
\quad q_n=|\xi_n|^2\approx |w_0(t_n)|^2\Delta t,
]
或者更稳（更贴近实验“成功出纤”概率）的是直接用未归一化通量：
[
Q_n=\int_{t_n}^{t_{n+1}} \Phi_{\rm out}(t),dt
=2\kappa_{\rm ex}\int_{t_n}^{t_{n+1}}|\alpha_g(t)|^2,dt,
]
[
P_S=\sum_n Q_n,\qquad q_n=\frac{Q_n}{P_S}.
]
这些关系你文档里也已经写得很清楚。

到这里，你就有了一个“目标离散概率质量” ({q_n})（以及如果你需要的话，还有每个 bin 的相位 (\phi_n=\arg \xi_n)）。

三、你问的关键点：每个 bin 的“矩阵幅度要多小”才能释放合适概率？

在你当前这种“顺序写入 bin”的幺正结构里，这个问题有一个非常直接、而且是离散精确（不是小量近似）的答案。

先忽略偏振、忽略 1517，仅看一个“未发射态 (|E\rangle)”与“该 bin 的单光子态 (|1_n\rangle)”之间的二能级耦合：如果第 (n) 步的发射门在单激发子空间里等效为
[
|E\rangle|0_n\rangle\ \mapsto\ \cos\theta_n,|E\rangle|0_n\rangle
+\sin\theta_n,|G\rangle|1_n\rangle,
]
那么最终“光子落在第 (n) 个 bin”的概率就是
[
q_n=\sin^2\theta_n\prod_{j<n}\cos^2\theta_j.
]

因此定义“条件发射概率”（在此前都没发射的前提下，在第 (n) 步发射）
[
\epsilon_n \equiv \frac{q_n}{1-\sum_{j<n}q_j},
]
就有非常干净的反解：
[
\sin^2\theta_n=\epsilon_n\quad\Rightarrow\quad
\theta_n=\arcsin\sqrt{\epsilon_n}.
]
这正是你文档里写的 (\epsilon_n=q_n/(1-\sum_{j<n}q_j)) 那条关系的“门参数版本”。

接下来把 (\theta_n) 和你代码里的参数对起来：

- 你的 `emission_gate` 里，指数的无量纲小参数就是 (\sqrt{\Delta t}\times\sqrt{\text{rate}})。
- 在单通道情形，若 (L=\sqrt{\Gamma_n},\sigma_-)，那么 (\theta_n=\sqrt{\Gamma_n\Delta t})。
- 所以你要的“每个 bin 作用的矩阵幅度”本质就是
  [
  \boxed{\theta_n=\sqrt{\Gamma_n\Delta t}=\arcsin\sqrt{\epsilon_n}.}
  ]
  进一步得到
  [
  \boxed{\Gamma_n=\frac{\theta_n^2}{\Delta t}
  =\frac{\arcsin^2\sqrt{\epsilon_n}}{\Delta t}.}
  ]

这就把“目标波包 ({q_n})”严格变成了“每一步 gate 的强度（物理速率）”。

四、把它落到你现有 `emission_gate` 的 (\gamma) 与 (L) 上（含一个你必须注意的 2 倍因子）

你现在不是单通道，而是两种正交偏振通道 (H/V)。你在 `emission_gate` 里构造了两个 Lindblad-like 的耦合算符 (L_H,L_V)，且它们都带了同一个 (\sqrt{\gamma})。

如果 `Alpha` 是酉矩阵（例如把 (\sigma^\pm) 变到 (H/V) 的标准情形就是酉的），那么从 (|e\rangle) 出发的“总耦合强度”满足
[
\langle e|(L_H^\dagger L_H+L_V^\dagger L_V)|e\rangle = 2\gamma,
]
也就是说，你当前代码里传进去的 `gamma` 更像“每个偏振通道的 rate”，总 rate 是 (2\gamma)。

这会直接影响你把 (\Gamma_n) 映射到代码参数的方式：

- 若你希望 (\Gamma_n) 表示“两个偏振合起来的总发射 rate”，那么建议把 `emission_gate` 内部改成
  [
  \sqrt{\gamma_{\rm per,mode}}=\sqrt{\Gamma_n/2}
  ]
  （也就是把现在的 `sqrt_gamma = sqrt(gamma)` 改成 `sqrt(gamma/2)`，并把函数参数语义改成“gamma_total”）。
- 如果你不想改 `emission_gate` 的实现，那也可以保持实现不变，但调用时传
  [
  \gamma_{\rm code}=\Gamma_n/2.
  ]

这一步不处理清楚，后面你会发现“用公式编译出来的 q_n”和“仿真跑出来的 q_n”总是差一截（通常是时间尺度/概率密度差一个因子）。

五、要不要把初态加到 (|5S_{1/2},F=1,m_F=0\rangle) 并显式打激发脉冲？

取决于你想“物理到什么程度”，以及你希望 (\Omega(t)) 在模型里扮演什么角色。

1）如果你的实验更像“先用很短的 (\pi) 脉冲把原子瞬间打到 (|e\rangle)，然后自由衰减/腔泄漏决定波包”
那么 (\Omega(t)) 的主要作用是决定“初始激发态制备的成功率/相位”，并不负责持续塑形。这个场景下，最干净的做法是：

- 依然把 MPS 发射阶段从 (|e\rangle) 起跑（你现在就是这样），
- 把“制备 (|e\rangle) 的不完美”折成一个初态混合或一个经典成功率（例如以概率 (p_{\rm prep}) 进入发射分支，否则进入无光子分支），
- 波包形状主要由腔/滤波决定。

2）如果你的实验目标是“用 (\Omega(t)) 主动塑形单光子波包”（vSTIRAP / cavity-assisted Raman 那类）
那就应该按 PRA 的物理图景来：初态是 (|u\rangle)，(|u\rangle\leftrightarrow|e\rangle) 由 (\Omega(t)) 驱动，(|g\rangle\leftrightarrow|e\rangle) 与腔耦合，波包由 (\Omega(t)) 控制。
就你当前工程而言，我建议的折中是：

- 在“波包生成器”里显式用 PRA 方程求 (\alpha_{u,e,g}(t))（这一步天然包含了“初态在 (|u\rangle)”与“激发脉冲形状 (\Omega(t))”）；
- 在 MPS 里继续沿用你现有的 3 能级自旋-偏振纠缠结构（(|e\rangle\to |0\rangle,|1\rangle) 并发出 (H/V)），只把“时间包络/相位”从 PRA 编译过来。

这样你既得到“更物理的时间波包”，又避免把 MPS 原子站点从 3D 扩到 4D/5D 造成全链维度改动（这是典型的关注点分离：包络来自腔 QED，偏振—自旋纠缠结构来自你原子模型）。

七、补充：如果你想让“source 效率/腔内损耗/自由空间自发辐射”也更物理

用 PRA 方程求出来的 (P_S) 本身就是“外耦合通道成功出光子”的概率（它由 (\kappa_{\rm ex}) 与损耗项共同决定）。
但你现在的 MPS 发射门是严格幺正的：不额外加 loss 的话，“激发最终一定会变成你显式模拟的光子”，这会高估源效率。

工程上有两个层次的补法（从轻到重）：

- 轻量补法（常用于系统级仿真）：把 (P_S) 当作源的“前置伯努利成功率”。成功则运行 emission（写入波包），失败则直接进入“无光子分支”。这会正确给出计数率，但会把“失败时原子最终态”粗糙化。
- 更一致的量子补法：把 PRA 模型里的“内损耗 (\kappa_{\rm in})”和“原子自发辐射 (\gamma)”做成额外的 Kraus/跳跃通道（不往你模拟的光纤模式里造光子），这样你不需要经典扔分支，系统会自然变成混态，最终 fidelity 会更贴近实验。

这一步如果你要做，我建议先从“源效率”入手（否则你后面调 fiber/detector 噪声时会发现源端过于理想，很多误差预算会失真）。
