## 0. 你要让对方实现的最小目标输出

实现一个函数：

**simulate(Ntraj) → $p_succ, rho_atom_cond, F_cond$**

- `Ntraj`：轨迹条数（Monte Carlo 次数）
- `p_succ`：成功概率估计
- `rho_atom_cond`：条件化（成功后）两原子密度矩阵（3×3 ⊗ 3×3 或投影到 qubit 子空间 2×2 ⊗ 2×2）
- `F_cond`：与目标 Bell 态的保真度

> 若你不想用轨迹（随机抽样），可以改做 MPO（密度矩阵）确定性演化，但这里默认用**纯态 MPS + 轨迹**，因为实现最像“矩阵乘 + SVD”。

## 1. 全局约定与输入参数（全是数组/矩阵）

### 1.1 时间离散

- 选择 `Δt`（double）
- 选择 `N`（int）：你要模拟的 time-bin 数（覆盖探测门宽/符合窗）
- `t[n] = n*Δt`，n 从 1 到 N（或从 0 到 N-1，二选一但要全局一致）

### 1.2 两臂参数（A/B）

给定（或外部生成）以下“纯数值对象”：

- `gamma_A[n]`、`gamma_B[n]`：发射耦合强度数组（≥0）
- `Alpha_emit_A`、`Alpha_emit_B`：2×2 复矩阵
  行 = (H,V)，列 = (+,-) 通道：
  $$
  \Alpha^{(\mathrm{emit})}=
  \begin{pmatrix}
  \alpha_{H,+} & \alpha_{H,-}\
  \alpha_{V,+} & \alpha_{V,-}
  \end{pmatrix}
  $$
  （对方无需懂几何怎么来；你给数即可）
- QFC：
  - `theta_H, theta_V`：实数（转换“角”）
- 光纤/器件损耗：
  - `eta_fiber_A`, `eta_fiber_B`：0~1（telecom 透过率）
  - `eta_ins_A_H, eta_ins_A_V, eta_ins_B_H, ...`（可选）偏振相关插损
- 偏振 Jones：
  - `J_A`, `J_B`：2×2 复矩阵（作用在 telecom (H,V)）
- PMD（可选）：
  - `Rin_A`, `Rout_A`, `Rin_B`, `Rout_B`：2×2 复矩阵
  - `m_A`, `m_B`：整数（= round(Δτ/Δt)）
- 相对到达时延失配（你最关心的 HOM 失配入口）：
  - `delta_bins`：整数（B 相对 A 的整体延迟，单位 bin）
  - 或 `delta_tau`：实数（秒），由 `delta_bins = round(delta_tau/Δt)` 得到
    这一步只影响“哪两个 bin 在 BS 上相遇”，**不需要引入 3×10^5 个真空 bin**（见第 8 节）。
- 探测参数：
  - `eta_det`：0~1
  - `p_dark`：0~1（每个探测器每个 bin 的暗计数概率）
  - `success_patterns`：成功事件集合（见第 7 节给一个严格可编码示例）
- 原子等待退相干（用来承载 80 μs 这种巨大绝对时延）：
  - `tau_wait`：秒（例如 80 μs 或含电子学/回传的总等待时间）
  - `gamma_phi`：1/秒（纯退相干率，或你定义的噪声模型参数）

> 上面这些都只是“数”。对方只需要把它们按公式塞进矩阵构造。

## 2. 站点排列（MPS 链）与局域维度（必须写死）

采用你们文档里推荐的排列（保证所有关键操作都能用相邻两站点门完成）：
$$
S;-;A_1;-;B_1;-;A_2;-;B_2;-;\cdots;-;A_N;-;B_N
$$
其中 `S` 是 system 复合站点（两原子 + 可选滤波腔），`A_n/B_n` 是第 n 个 time-bin 的场站点。

### 2.1 bin 站点局域基（强制要求：能容纳两光子 sector）

为了让 50/50 BS 后的 bunching 不“跑出截断空间”，每个臂每个 bin 至少要支持**同一臂同一 bin 内出现 2 光子**。这一点你们流水表也明确强调过。

这里给一个最稳的可闭合选择（推荐第一版）：

- 每臂每 bin 有 4 个 bosonic 模式：
  `mode 0=b_H(780)`, `mode1=b_V(780)`, `mode2=c_H(1517)`, `mode3=c_V(1517)`
- 局域 Fock 基用 occupancy 四元组
  $$
  (n_0,n_1,n_2,n_3),\quad n_i\in{0,1,2},\quad n_0+n_1+n_2+n_3\le 2
  $$
- 这种截断下每臂每 bin 的维度 **d_bin = 15**（你可以让程序自动枚举）

**必须给对方一个固定的 basis 编码规则**：
用一个“字典/数组”存所有 occupancy 四元组，按字典序排序（或你指定的任何唯一顺序）：

- `basis_bin = sorted([occ for occ in {0,1,2}^4 if sum(occ)≤2])`
- `index_bin[occ] = position in basis_bin`

之后所有 bin 内矩阵都以这个基为准。

### 2.2 system 站点局域基（最小可跑版）

最小可跑版只含两原子、无滤波腔（你要滤波记忆再加）：

- 单原子基：`|0>, |1>, |e>` → 维度 3
- 两原子 system：维度 `d_atom = 3*3=9`

若加入滤波腔（每臂每偏振一个腔模，截断到 0/1）：

- 腔模数：4 个（A,H / A,V / B,H / B,V）
- 每个腔模维度 2（0/1）
- `d_cav = 2^4=16`
- system 总维度 `d_S = 9 * 16 = 144`

同样必须指定 system basis 编码规则，例如：

```
basis_S = (aA in {0,1,e}) × (aB in {0,1,e}) × (n_AH,n_AV,n_BH,n_BV in {0,1})
```

## 3. 必须实现的“基础矩阵工厂”（只做矩阵，不讲物理）

对方要先写几个通用函数（你可以直接当作接口要求）：

### 3.1 多模 Fock 截断基的湮灭矩阵

**输入：**

- `basis`: list of occupancy tuples，长度 d
- `mode_id`: int（0..M-1）

**输出：**

- `a`：d×d 复矩阵

**填充规则（唯一且无歧义）：**

对每个 occupancy `occ`：

- 若 `occ[mode_id]=n>0`：
  - `occ2 = occ` 但把该分量改为 `n-1`
  - 令 `i=index(occ)`，`j=index(occ2)`
  - `a[j,i] = sqrt(n)`
- 其它元素 0

创建算符 `adag = a.conj().T`。
数目算符 `n = adag @ a`。

> 这是整个工程的“原子级 primitive”。所有门都用它们拼起来。

### 3.2 system 上的原子跃迁矩阵

先给单原子 3×3 的矩阵$基顺序固定为 `[|0>,|1>,|e>]`$：

- [
  S_+ = |0\rangle\langle e| \Rightarrow $S_+$_{0,2}=1
  ]
- [
  S_- = |1\rangle\langle e| \Rightarrow $S_-$_{1,2}=1
  ]

两原子 system 里：

- `S_A_plus = S_plus ⊗ I3`
- `S_A_minus = S_minus ⊗ I3`
- `S_B_plus = I3 ⊗ S_plus`
- `S_B_minus = I3 ⊗ S_minus`

若 system 还包含腔模，就在 Kronecker 时再 ⊗ `I_cav`。

### 3.3 Kronecker 嵌入规则（写死）

当你要在 system×bin 空间上构造矩阵时：

- system 算符 `O_S`$d_S×d_S$
- bin 算符 `O_B`$d_bin×d_bin$

联合空间算符 = `kron(O_S, O_B)`$维度 $d_S*d_bin$×$d_S*d_bin$$。

## 4. 必须实现的 MPS 基本算子（全是张量收缩 + SVD）

你要对方写一个 MPS 类（或结构体）：

- 链长 `L = 1 + 2N`
- 每个站点 k 有局域维度 `d[k]`：
  - `d[0]=d_S`
  - `d[1]=d_bin` (A1)
  - `d[2]=d_bin` (B1)
  - ...
- MPS 张量列表 `A[k]`，shape：
  - `A[k]` 是三阶张量 `(χ_left, d[k], χ_right)`
- 允许最大 bond `χ_max` 或截断阈值 `eps`

### 4.1 two-site 门更新（TEBD 核心）

函数：`apply_two_site_matrix(MPS, k, U, χ_max, eps)`

- 输入：
  - k：站点索引（对 (k,k+1)）
  - `U`：矩阵形状 `(d[k]*d[k+1], d[k]*d[k+1])`
  - 物理基扁平化顺序：
    `p = s_k * d[k+1] + s_{k+1}`（row-major）

**步骤（必须完全按这个写）：**

1. 取出 `A = A[k]` shape `(χL, d1, χM)`，`B = A[k+1]` shape `(χM, d2, χR)`
2. 合并为四阶张量
   $$
   \Theta[\alpha, s, t, \gamma] = \sum_{\beta} A[\alpha,s,\beta];B[\beta,t,\gamma]
   $$
   代码就是一次张量收缩。
3. 把 `(s,t)` 扁平化成 `p`：
   `Θ_flat` shape `(χL, d1*d2, χR)`
4. 作用矩阵 U（只作用在物理指标 p 上）：
   $$
   \Theta'*{\alpha,p',\gamma}=\sum*{p} U_{p',p};\Theta_{\alpha,p,\gamma}
   $$
   这就是矩阵乘（可以用 einsum 或 reshape 后 matmul）。
5. 把 `Θ'` reshape 回四阶 `(χL,d1,d2,χR)`，然后 reshape 成矩阵
   `M` shape `(χL*d1, d2*χR)`，其中
   `row_index = α*d1 + s`
   `col_index = t*χR + γ`
6. SVD：`M = USV†`
   - 根据 `χ_max` 或 `eps` 截断：只保留前 χ_new 个奇异值
7. 回写两张量：
   - `A[k] = reshape(U, (χL, d1, χ_new))`
   - `A[k+1] = reshape(S*V†, (χ_new, d2, χR))`

> 这一步就是你们文档里说的“施加局域门后做 SVD 截断”。

### 4.2 one-site 门更新

函数：`apply_one_site_matrix(MPS, k, U)`

- `U` shape `(d[k], d[k])`
- 更新：
  $$
  A'[k]*{\alpha,s',\beta}=\sum_s U*{s',s},A[k]_{\alpha,s,\beta}
  $$

### 4.3 计算 norm²（用于 Kraus 抽样）

函数：`norm2(MPS)`
返回 $\langle\Psi|\Psi\rangle$。

实现方式不限，但必须正确。（最简单：从左到右做环境收缩。）

## 5. “门/信道”都写成矩阵或 Kraus 集：如何构造

下面每个模块都只用你在第 3 节造出来的基本矩阵拼起来。它们对应你们总设计图纸和流水表里的模块顺序。

### 5.1 发射模块：`U_emit(j,n)`（system×bin 的方阵）

对臂 `j∈{A,B}`，对 bin `n`：

1. 取 system 上的跳矩阵
   `S_j_plus`, `S_j_minus`
2. 从 `Alpha_emit_j` 取 4 个复数：
   `αH+ , αH- , αV+ , αV-`
3. 计算 system 上两个矩阵$仍是 d_S×d_S$：
   $$
   L_{H} = \sqrt{\gamma_j[n]},(\alpha_{H,+} S_{j,+}+\alpha_{H,-} S_{j,-})
   $$
   $$
   L_{V} = \sqrt{\gamma_j[n]},(\alpha_{V,+} S_{j,+}+\alpha_{V,-} S_{j,-})
   $$
4. bin 上取 780 的湮灭矩阵：`b_H`, `b_V`，以及共轭转置 `b_H†`, `b_V†`
5. 构造生成矩阵$联合空间 $d_S*d_bin$×$d_S*d_bin$$：
   $$
   G_{\mathrm{emit}}=\sqrt{\Delta t}\Big(
   L_H\otimes b_H^\dagger + L_V\otimes b_V^\dagger
   -L_H^\dagger\otimes b_H -L_V^\dagger\otimes b_V
   \Big)
   $$
6. 输出：
   $$
   U_{\mathrm{emit}}=\exp(G_{\mathrm{emit}})
   $$
   $矩阵指数，`expm`$

### 5.2 QFC：`U_qfc`（bin 内 one-site 方阵）

在每个 bin 的局域 15 维空间里已有 `b_H,b_V,c_H,c_V`：

构造：
$$
G_{\mathrm{QFC}}=-i\Big[\theta_H,(b_H c_H^\dagger+b_H^\dagger c_H)+\theta_V,(b_V c_V^\dagger+b_V^\dagger c_V)\Big]
$$
注意这里的乘法是**矩阵乘**（同一 site 的不同模式算符）。

$$
U_{\mathrm{QFC}}=\exp(G_{\mathrm{QFC}})
$$
`U_qfc` 与 n 无关则只算一次。

### 5.3 滤波/记忆（可选）：`U_filt(j)`（system×bin）

若 system 内含腔模 `a_{j,H}`, `a_{j,V}`$d_S×d_S$：

- bin 上取 telecom：`c_H`, `c_V`

构造（示例一阶离散碰撞门）：
$$
G_{\mathrm{filt}}=
\sqrt{\kappa_f\Delta t}\Big[
a_H\otimes c_H^\dagger-a_H^\dagger\otimes c_H
+
a_V\otimes c_V^\dagger-a_V^\dagger\otimes c_V
\Big]
-i\Delta t;H_f\otimes I_{\mathrm{bin}}
$$
其中 $H_f$ 你可以选 $H_f=\Delta_f(a_H^\dagger a_H + a_V^\dagger a_V)$（矩阵在 system 上）。

$$
U_{\mathrm{filt}}=\exp(G_{\mathrm{filt}})
$$

> 如果你暂时不想做滤波记忆，就把这一步删掉（但你们总设计图纸里它是推荐模块）。

### 5.4 telecom 偏振 Jones：`U_pol(j)`（bin 内 one-site 方阵）

输入是 2×2 复矩阵 `J_j`，作用在 `(c_H,c_V)`。

**最不歧义的实现（推荐）：用二次型生成元 + expm**

1. 求一个 2×2 复矩阵 `K_j` 使得
   $$
   J_j=\exp(-iK_j)
   $$
   $程序上可用 `logm`：`K_j = i*logm(J_j)`，然后强制取 Hermitian 部分 `(K+K†)/2`$
2. 构造 bin 内矩阵：
   $$
   H_{\mathrm{pol}}=\sum_{p,q\in{H,V}} (K_j)_{pq};c_p^\dagger c_q
   $$
3. 输出：
   $$
   U_{\mathrm{pol}}=\exp(-iH_{\mathrm{pol}})
   $$

这给出一个 **15×15** 的 `U_pol`（它对 780 子空间自然是“近似恒等”，因为里面没有 c†c 项）。

### 5.5 损耗（器件/光纤）：Kraus 集（one-site）

对每个 mode$例如 `c_H` 这个单模式$，给定透过率 `η`，在单模式截断 n≤2 下，Kraus 有 3 个（丢 0/1/2 个光子）：

$$
K_k=\sum_{n=k}^{2}\sqrt{\binom{n}{k}};\eta^{(n-k)/2}(1-\eta)^{k/2};|n-k\rangle\langle n|,\quad k=0,1,2
$$

**你必须让对方把它“嵌入”到 15 维 bin 基里**：

对于每个 basis state `occ=(n0,n1,n2,n3)`，选定你要损耗的 mode_id（比如 telecom H 是 mode2）：

- 若该 mode 占据 `n = occ[mode_id]`
- 对每个 `k=0..min(n,2)`：
  - 目标 occupancy：把该 mode 改为 `n-k`，其它不变 → `occ2`
  - `K_k[index(occ2), index(occ)] += sqrt(C(n,k)) * η^((n-k)/2) * (1-η)^(k/2)`

这样得到每个 `K_k` 都是 15×15。

**多模式损耗的执行规则（写死）：**
不要一次性构造 4-mode 的巨大 Kraus 直积；而是按 mode 逐个串联，顺序固定$例如：先 `c_H` 再 `c_V`，再 `b_H` 再 `b_V`$。每个 mode 都进行一次 Kraus 抽样并更新 MPS。

### 5.6 BS（中站 50/50）：`U_BS`$two-site 方阵，作用在 $A_n,B_n$$

只混合 telecom 模式$mode2=c_H、mode3=c_V$，对 H 和 V 两个偏振各一个 50/50 BS，角取 $\theta=\pi/4$。

对某个偏振 p（例如 H）：

- 在 A site 上取 `c_{A,p}`（15×15），在 B site 上取 `c_{B,p}`（15×15）
- 联合空间的生成元：
  $$
  G_{\mathrm{BS},p}=\theta\Big(c_{A,p}^\dagger\otimes c_{B,p}-c_{A,p}\otimes c_{B,p}^\dagger\Big)
  $$
- H 与 V 的生成元相加：
  $$
  G_{\mathrm{BS}}=G_{\mathrm{BS},H}+G_{\mathrm{BS},V}
  $$
- 输出：
  $$
  U_{\mathrm{BS}}=\exp(G_{\mathrm{BS}})
  $$
  它是 225×225（因为 15×15 两站点）。

## 6. PMD / 时延（跨 bin）必须写成“置换矩阵/Swap 网络”

这里是你最在意的“别玩具化”的地方：**时延就是一个索引移位/置换**。

### 6.1 “单臂整体时延 delta_bins”两种等价实现（你选一种写死）

#### 方案 A（最简单，强烈推荐）：直接把发射 envelope 平移

把 B 臂的 `gamma_B[n]` 替换成：

- `gamma_B_shift[n] = gamma_template[n - delta_bins]`（越界处补 0）

然后主循环里 BS 永远作用在 `(A_n,B_n)`。
**这已经完整体现了 HOM 对齐偏移**：因为两臂波包在 bin 上不再对齐。

> 这就是“把巨大空间延迟等效成对齐偏移”的核心：你只需要相对偏移，不需要 3×10^5 个空 bin。

#### 方案 B（更通用）：对 telecom 子空间做“delay-line 置换网络”

把 B 臂 telecom 模式整体向前/向后移 `delta_bins` 个 bin。
实现为对 B 臂的 bin 序列做 SWAP 链置换（类似 PMD 子程序，但作用对象是两偏振 telecom 一起）。

对 `delta_bins=1` 的“向后移 1 格”示例$把 B_k 的 telecom 内容推到 B_{k+1}$：

- 对 k=1..N-1，依次对相邻站点 `(B_k, B_{k+1})` 施加一个 two-site **置换矩阵** `SWAP_telecom`：
  - 它只交换两站点中 telecom 两个 mode $c_H,c_V$ 的 occupancy，其它 mode 保持不动。

`SWAP_telecom` 的构造规则也必须写死：
对 product basis `occL, occR`（都是 4-tuple）：

- 交换其中 `mode2,mode3` 的占据数：
  - new_occL = (n0L,n1L, n2R,n3R)
  - new_occR = (n0R,n1R, n2L,n3L)
- 置换矩阵元素：
  $$
  [SWAP]_{(new_occL,new_occR),(occL,occR)} = 1
  $$
  其它 0。

`delta_bins>1` 就重复扫 `delta_bins` 轮。

### 6.2 PMD（差分时延）实现（你们流水表的“PSP 基 + SWAP 链”机械化）

PMD 的整数版本：给定 `m_j`（PSP2 相对 PSP1 延迟 m 个 bin）

对臂 j 的未测区间 bins `[n..N]`，执行子程序：

1. 对每个 bin k=n..N：在该 bin 上施加 one-site `U_Rin`$按 5.4 的同样方式由 `Rin_j` 构造$，只作用 telecom (H,V) 子空间。
2. 做 `m_j` 轮 shift：每一轮都对 k=n..N-1 施加一次 two-site `SWAP_PSP2(k,k+1)`：

- `SWAP_PSP2` 的构造规则：
  - 先明确在 Rin 之后，你的“telecom 两模式”现在代表 (PSP1, PSP2)
    即把 `mode2` 解释为 PSP1，把 `mode3` 解释为 PSP2（或你指定相反，但必须写死）
  - 该 SWAP 只交换 PSP2（比如 mode3）在相邻两 bin 的占据数，其他 mode 不动：
    - new_occL = (n0L,n1L,n2L, n3R)
    - new_occR = (n0R,n1R,n2R, n3L)
  - 置换矩阵按同样的 “basis→basis 映射置 1” 规则填充

1. 对每个 bin k=n..N：施加 one-site `U_Rout`$由 `Rout_j` 构造$。

## 7. 探测：必须实现为“对角 Kraus”并给出成功事件判据（可编码）

### 7.1 单个探测器模式的 on/off POVM（截断到 n≤2）

给定 `eta_det`、`p_dark`：

- 对一个单模式占据数 n：
  - no-click 概率因子：$(1-p_{\rm dark})(1-\eta_{\rm det})^{n}$
- 所以 no-click POVM 元素（对角）：
  $$
  E_0 = \sum_{n=0}^{2}(1-p_{\rm dark})(1-\eta_{\rm det})^{n},|n\rangle\langle n|
  $$
- click：
  $$
  E_1 = I - E_0
  $$
  Kraus 取平方根（仍对角）：
  $$
  M_r=\sqrt{E_r},\quad r\in{0,1}
  $$

### 7.2 你这套 setup 的 4 个探测器（每个 bin）

在做完 `U_BS` 后，把：

- A_n site 的 telecom H/V 当作“输出口 1 的 H/V”
- B_n site 的 telecom H/V 当作“输出口 2 的 H/V”

因此四个 on/off 结果是：

- `r(1H), r(1V), r(2H), r(2V)`，每个是 0/1

实现上你可以“逐探测器顺序测量”（因为这些 Kraus 都对角且彼此对易）：

1. 在 A_n 上对 telecom H 模式应用 `{M0, M1}`（one-site 对角算子）
2. 在 A_n 上对 telecom V 模式应用 `{M0, M1}`
3. 在 B_n 上对 telecom H 模式应用 `{M0, M1}`
4. 在 B_n 上对 telecom V 模式应用 `{M0, M1}`

每一步都需要：

- 计算两种结果概率 `p0=||M0|Ψ>||^2`, `p1=||M1|Ψ>||^2`
- 抽样 r∈{0,1}
- 更新 `|Ψ> ← M_r|Ψ>/sqrt(p_r)`

（如果你不想随机抽样，就做 MPO。）

### 7.3 成功事件集合（一个“严格可编码”的例子）

你必须给程序员一个**明确的 bool 判定函数**。比如（典型的部分 BSM）：

- 成功当且仅当存在某个 bin n 使得：
  - `r_n` 恰好有两个 1，且是：
    - (1H=1 且 2V=1 且其它=0)，或
    - (1V=1 且 2H=1 且其它=0)
- 且所有其它 bin 的 `r_k` 全 0（或允许你定义一个“符合窗宽 w”，即允许点击出现在相邻 bin，但你必须写成明确规则）

这条规则完全可以写成程序里的 if/else。

## 8. 你质疑的核心：80 μs 传播时延怎么“等效”而不引入 10^5–10^6 真空 bin

这一段我只用“置换矩阵”说清楚（不讲概念）。

### 8.1 传播时延 = bin 标签的置换

离散后，单向传播时延 $N_\tau=\mathrm{round}(\tau/\Delta t)$ 等价于对 bin 序列施加一个置换（Permutation）：

- 把“携带内容的 bin”整体从位置 n 移到 n+Nτ
- 中间补的 Nτ 个 bin 初态都是 vacuum

写成张量积态就是：
$$
|\psi\rangle_{1..K}\otimes |vac\rangle^{\otimes N_\tau}
\quad\xrightarrow{;\Pi_\tau;}\quad
|vac\rangle^{\otimes N_\tau}\otimes |\psi\rangle_{1..K}
$$

这里 $\Pi_\tau$ 是一个**纯置换矩阵**（只做 index 交换），它不会制造纠缠；vacuum 是直积态。

**结论（数值实现的硬规则）：**
只要你不做“时间复用/多轮并行让不同尝试的波包在光纤里重叠”，那么你根本不需要显式维护那 $N_\tau$ 个真空 bin；你只需要：

1. 用 `delta_bins`（相对到达偏移）处理 A/B 对齐 → 决定 HOM/BSM；
2. 用 `tau_wait` 对 system 做一次等待退相干通道 → 承载 80 μs 的物理后果。

这正是你之前担心“否则变玩具”的那条链闭合方式。

### 8.2 等待退相干：只在 system 上做一个 one-site 通道

例如纯退相干（你可换成别的噪声，但必须是明确矩阵/Kraus）：

- 给单原子 qubit 子空间（|0>,|1>）的相位噪声，参数
  $p_\phi = 1-e^{-\gamma_\phi \tau_{\rm wait}}$

Kraus（在 qubit 上）：

- $K_0=\sqrt{1-p_\phi},I$
- $K_1=\sqrt{p_\phi},Z$

把它嵌入到 3 维（|0>,|1>,|e>）上，你必须写死一种做法，比如：

- 让 |e> 不参与（或同样受噪声），用 block-diag 扩展到 3×3
- 两原子 system 就 Kronecker：对 A、B 各自作用

然后在“本次尝试结束、判断成功后”对 system 应用一次（因为它与光场测量对易，数值上等价）。

### single_trajectory()

**初始化：**

1. 构造长度 `L=1+2N` 的 MPS：

- `A[0]` 是 system 初态$例如 |e,e, cav_vac>$，shape $1, d_S, 1$
- 对所有 bin 站点 k≥1：设为 vacuum 基向量，shape $1, d_bin, 1$

**轨迹记录：** `record = []`

**for n = 1..N：**

0)（可选）system 噪声小步：对 site0 施加 one-site Kraus/矩阵（你若不做连续噪声，可跳过）

1. `U = U_emit(A,n)`$按 5.1 构造，维度 d_S*d_bin$
   - `apply_two_site_matrix(MPS, k=0, U)` 作用在 $S, A_n$
     注意：此时 S 必须紧挨 A_n（下面用 SWAP 维持这个不变式）
2. `apply_one_site_matrix(MPS, k=site(A_n), U_qfc)`

3)（可选滤波）`apply_two_site_matrix(MPS, (S,A_n), U_filt(A))`

4)（损耗串联）对 A_n 的各 mode 依次做 Kraus 抽样更新

- for mode in [telecom H, telecom V, (可选 780 H/V)]：
  - 构造该 mode 的嵌入 Kraus `{K0,K1,K2}`（15×15）
  - `apply_one_site_kraus_sample(MPS, site(A_n), {Kk})`

1. `apply_one_site_matrix(MPS, site(A_n), U_pol(A))`
2. **SWAP$S, A_n$**：
   - 构造置换矩阵 `W_swap(d_S,d_bin)`：`W|s>⊗|t> = |t>⊗|s>`
   - `apply_two_site_matrix(MPS, between S and A_n, W_swap)`
     此后 system 站点移动到 A_n 右侧，紧挨 B_n（流水表的“传送带”）。
3. 重复 A 的 (1)–(5)，把 A 换成 B，作用在 $S,B_n$ 与 B_n
4. **SWAP$S, B_n$**（同 6）：把 system 再移到 B_n 右侧，使得 A_n 与 B_n 相邻以便做 BS。

13)（可选）PMD 子程序：对未测 bins 区间施加（第 6.2 节给的 Rin + SWAP 链 + Rout）

1. `apply_two_site_matrix(MPS, sites(A_n,B_n), U_BS)`（按 5.6 构造）
2. 探测（按 7.2 逐探测器测量，抽样 0/1 并更新）：

- 得到 4-bit 结果 `r_n = (1H,1V,2H,2V)`
- `record.append(r_n)`

1. 丢弃 A_n 与 B_n（推荐，保证线性复杂度）：

- 在实现上最机械的方式是：因为已测量后它们应接近 product state，把这两个站点的张量规范化到 bond=1，然后从链上 delete 这两个站点（或保持但不再参与计算）。
  $你可以要求实现者：必须提供 `discard_measured_pair(A_n,B_n)` 函数。$

**循环结束**

**成功判定：**

- `succ = is_success(record, success_patterns)`（第 7.3 节）

若 `succ==False`：返回 “失败标记”。

若 `succ==True`：

1. 从最终 MPS 中提取 system 纯态向量 `psi_S`（此时链应该只剩 system 或 system+少量内部模）
2. （等待退相干）对 system 应用 one-site channel `E_wait(tau_wait)`（第 8.2 节），得到 `rho_S`（或仍用轨迹抽样）
3. 从 `rho_S` 做 partial trace 去掉腔模（若存在），只保留两原子：

- 如果 system basis 是 `(atomA, atomB, cav...)`：
  - reshape `psi_S` 或 `rho_S` 成张量
  - 按腔模指标求和得到 `rho_atom`（纯矩阵乘/求和）

1. 返回 `rho_atom`。

## 11. 三个“必过的单元测试”（防止玩具化/索引错）
