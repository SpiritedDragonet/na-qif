1）关于“做体现 MPS 优势的仿真”，对实验提高保真度的实际收益，我的严谨判断是：收益取决于你用它回答什么问题；在你这类 30 km、herald 稀有、并且你又明确要输出 ((p_{\rm succ},\rho_{AB|\rm succ},F)) 的场景里，MPS 的收益通常不是“把全过程按实验重复到成功”，而是“把成功条件化后的态与成功率拆解成可归因的误差预算，并给出对可控旋钮的敏感性”。如果你沿这个方向用 MPS，收益是中到高；如果你把 MPS 当作“逐次复现实验直到双击”的机器，收益低且成本极高。

为什么我这样说（把“值”落到你系统里）：

(1) 你现在的建模目标本来就写成了实验最需要的三元组输出：一次尝试的成功概率、成功后的两原子条件态、以及其保真度。 这就意味着，你的“对实验有指导价值”的核心，不是某条轨迹的叙事性，而是这些量对噪声与参数的依赖曲线。

(2) 在 30 km 低成功率区域，实验上提升保真度最常见、也最“硬”的瓶颈往往是两类：
A. “真成功越来越少、假成功（暗计数/背景触发的双击）比例上升”，导致 (\rho_{AB|\rm succ}) 被假阳性混合稀释；
B. 干涉不可区分性（偏振/时域/频域模式失配）下降，导致“即使是真光子触发的成功”也不是理想 Bell 投影。
这两类瓶颈的共同点是：它们都通过“条件化（post-selection）”进入结果，而条件化的偏置效应用简单解析模型很容易写错或漏项；用你现在的 “Kraus + MPS + BSM/探测”框架可以统一处理。你在 spec 里甚至把“成功事件集合 success_patterns”“探测效率/暗计数”作为输入对象显式写出来了。

(3) 另外一个你系统里“结构性必须正确”的点是：一旦你真的做中站 BS 干涉（哪怕只是 telecom 子空间），你必须保证局域截断能容纳两光子 sector，否则 bunching 后会“跑出截断空间”，成功率与点击统计会系统性偏。你们的 spec 已经把这一点写成强制要求（并给了推荐的 (d_{\rm bin}=15) 截断构造）。 你当前基础子空间定义里，1517 子空间也确实包含 (|2H\rangle,|2V\rangle,|HV\rangle)（6 维），这是向正确方向走的。
在这种约束下，MPS 的价值不只是“能跑大系统”，而是“能保证门/测量闭合性 + 条件化统计一致性”。

(4) “体现 MPS 优势”的那两项更硬核（滤波记忆的非马尔可夫、PMD 跨 bin 混合）是否带来额外收益，确实要看你实验链路是否存在足够长的记忆时间或足够强的跨 bin 混合；但即便你暂时不引入它们，MPS 仍然能在 (2)(3) 这两类真实瓶颈上提供可操作的指导。你的总设计图纸也明确把“滤波记忆、PMD、探测条件化”当作整条流水的模块化组件，而不是装饰品。

所以我会给一个“工程式”的结论：
如果你用 MPS 做的是“输出 ((p_{\rm succ},F)) 对门宽/符合窗/暗计数/背景/QFC 噪声/偏振漂移的敏感性，并拆出假阳性占比”，它对实验提高保真度的收益通常很大；
如果你用 MPS 做的是“尽可能拟真地跑到第 1 次成功”，收益不大，且会把算力浪费在被丢弃的失败上。

2）关于“不跑几百万次”的前提下，怎样最准确地算宣告成功概率、生成成功样本，并评估后验保真度与先验保真度差距：我建议你把问题严格写成“成功事件集合上的 POVM 条件化”，然后用“枚举成功记录 + 强制 Kraus 分支（postselection）+ 加权求和”的方式在一次尝试层面给出几乎无偏、且计算量可控的结果；再在外层处理漂移/慢噪声；最后用“真成功/假成功分解”把先验与后验的差距归因。

下面是可直接落到你现有框架的做法（不需要百万次失败）：

2.1 把 herald 成功写成集合 (\mathcal S) 上的条件化

你真正要的量可以严格写成：

对每一个完整点击记录 (r)（例如 N 个 time-bin、每个 bin 4 个探测器 on/off，所以 (r={r_n}_{n=1}^N)），存在对应的测量 Kraus (M_r)。则

[
p_r=\lVert M_r|\Psi_{\rm pre}\rangle\rVert^2,
\qquad
\rho_{AB|r}=\frac{\mathrm{Tr}*{\rm field}!\left(M_r|\Psi*{\rm pre}\rangle\langle\Psi_{\rm pre}|M_r^\dagger\right)}{p_r}.
]

成功事件集合 (\mathcal S)（你 spec 里叫 success_patterns，本质就是这个集合）给出：

[
p_{\rm succ}=\sum_{r\in\mathcal S} p_r,
\qquad
\rho_{AB|\rm succ}=\frac{1}{p_{\rm succ}}\sum_{r\in\mathcal S} p_r,\rho_{AB|r}.
]

这就是“最准”的定义：在你选择的物理模型与离散化下，它是精确的（误差只来自截断 (\chi_{\max})、(\Delta t)、局域 Fock 截断等数值近似）。你们的目标输出也正是这三项。

关键难点在于：(r) 的总数是指数大，但 (\mathcal S) 往往很小（例如“恰好双击且满足某种组合”通常是 (O(N)) 或 (O(Nw)) 的规模），所以“只对 (\mathcal S) 枚举”是可行的。

2.2 不靠抽样：在你 MPS 里实现“强制 Kraus 分支 + 返回概率权重”

你现在的 MPSState 已经有 apply_kraus_one_site / apply_two_site_kraus，它们会计算每个 Kraus 的概率再抽样一个分支。
你需要的只是同一逻辑的“非抽样版本”，核心是：指定 (\mu) 分支并把该分支的概率 (p_\mu) 返回出来。

推荐的数值稳定写法是“归一化态 + 外部权重”：

- 维护一个标量权重 (w)（初始 (w=1)）。
- 每次强制应用某个 Kraus (K_\mu) 时，先算
  [
  p_\mu=\lVert K_\mu|\psi\rangle\rVert^2,
  ]
  然后更新
  [
  |\psi\rangle\leftarrow \frac{K_\mu|\psi\rangle}{\sqrt{p_\mu}},
  \qquad
  w\leftarrow w\cdot p_\mu.
  ]
- 最后 (w) 就是整条记录 (r) 的概率 (p_r)（完全等价于不归一化一路乘下去，但数值稳定得多）。

这样你只需要跑“成功记录的数量”次，而不是跑 (1/p_{\rm succ}) 次失败。

你可以把“对一个给定记录的强制测量”做成顺序扫描，逐 bin 应用并及时归一化；当前实现已不再使用 finalize_bin_pair。

2.3 怎样“最准”地算 (p_{\rm succ})：枚举成功记录并求和（而不是跑到成功）

假设你的 herald 条件是典型的“在某个 bin（或符合窗内）出现特定双击、其它 bin 无额外点击”。那么 (\mathcal S) 的规模通常是：

- 同一 bin 双击：(|\mathcal S| \sim N \times (\text{有限个双击模式}))；
- 两个 bin 内双击（符合窗 (w)）：(|\mathcal S|\sim Nw \times (\text{有限个模式组合}))。

对每个候选成功记录 (r\in\mathcal S) 做一次“强制 Kraus 扫描”，得到 ((p_r,\rho_{AB|r}))。最后加权求和得到 (p_{\rm succ}) 与 (\rho_{AB|\rm succ})。

这一步的计算量从“几百万次全轨迹”降到“大约 (|\mathcal S|) 次强制轨迹”。在 N=200、成功模式很少的情况下，它通常是几百到几千次级别，而不是 (10^6) 级别。

重要细节：如果你要“最准”，必须确保你的局域 Hilbert 空间在 BSM/BS 后是闭合的。你 spec 已经明确写了“bin 至少要支持 2 光子 sector”来避免 BS bunching 溢出。 你当前 1517 子空间的 6 维确实包含两光子态（2H/2V/HV），这是满足闭合性的必要条件之一。 如果你在某些阶段用的是 5 维压缩 bin（只含单光子），那一阶段就不适合拿来做最终 (p_{\rm succ}) 与 (F) 的定量结论。

2.4 怎样得到“宣告成功的试验样本”：直接从 (p(r|\rm succ)) 采样，而不是从失败里等

实验上你要的是：一堆成功事件（每个事件有一个点击记录、以及随后对原子的测量结果）。在仿真里你可以直接从条件分布生成：

[
p(r|\rm succ)=\frac{p_r}{p_{\rm succ}},\quad r\in\mathcal S.
]

做法是：

- 先用上面的枚举法算出所有 (p_r)；
- 在 (\mathcal S) 上按权重 (p_r) 抽样得到一串成功记录 (r^{(1)},\dots,r^{(K)})；
- 对每个抽到的 (r^{(k)})，你已经在计算 (p_r) 时拿到了 (\rho_{AB|r^{(k)}})（或对应的纯态）；你再在原子测量基上按 Born rule 抽样，生成“实验读出结果”。

这就给你一个“只包含成功样本”的仿真实验数据集，统计上与“真实实验反复激发直到成功”一致，但完全不需要把失败试次显式模拟出来。

2.5 漂移/随机噪声怎么并入：要用“成功概率加权”的后验平均

你在 total_simulation.py 里已经把光纤/器件漂移建成了外层随机参数（随机 Jones 旋转、透过率波动、相位漂移等）。 这种“慢漂移/外参”下，实验里成功样本对漂移是有偏抽样的。正确的后验平均是：

对每个漂移样本 (x)（例如一组 (U_A,U_B,\eta,\phi)），你算出
((p_{\rm succ}(x),\rho_{AB|\rm succ}(x)))。那么总体“成功后的平均条件态”必须是

# [ \bar\rho_{AB|\rm succ}

\frac{\mathbb E_x!\left[p_{\rm succ}(x),\rho_{AB|\rm succ}(x)\right]}
{\mathbb E_x!\left[p_{\rm succ}(x)\right]},
\qquad
\bar p_{\rm succ}=\mathbb E_x[p_{\rm succ}(x)].
]

这一步非常关键：很多人脑海里的“先验”其实是 (\mathbb E_x[\rho_{AB|\rm succ}(x)])（不加权），但实验真正看到的是上面这个“按成功率加权”的后验。也正是这里会出现你关心的“后验与先验差距”，而这差距在低成功率场景是可以很大的。

2.6 “后验保真度 vs 先验保真度”怎么定义、怎么把差距拆出来

你问的“先验”在实验语境里常见有两种含义。你最好把两种都算出来，并把差距归因，否则很容易鸡同鸭讲。

先验 A（理想化先验）：大家“以为”双击就意味着理想 Bell 投影，只考虑不可区分性/源端退相干等“真事件”因素。
实现上你可以在仿真里把暗计数/背景关掉（(p_{\rm dark}=0)，或去掉 QFC 背景项），只保留物理光子与干涉失配，得到
[
F_{\rm prior}^{\rm ideal} = \langle\Phi|\bar\rho^{(p_{\rm dark}=0)}_{AB|\rm succ}|\Phi\rangle.
]

后验（真实可观测后验）：把暗计数/背景/插损等全部打开，用上文的加权平均得到
[
F_{\rm post}=\langle\Phi|\bar\rho_{AB|\rm succ}|\Phi\rangle.
]

两者差值 (\Delta F = F_{\rm post}-F_{\rm prior}^{\rm ideal}) 就是“现实 herald 机制把你从理想预期拉下来的量”。

更进一步（我建议你一定做）：把后验写成“真成功 + 假成功”的凸组合，这样你能直接给实验同事一个可行动的指标——假阳性占比。

把成功事件拆成两类：

- true herald：至少有“真实到达并参与了干涉/探测”的光子贡献；
- false herald：纯暗计数/纯背景触发的成功模式（或本质上与两原子纠缠无关的触发）。

你可以通过两种方法拿到这个分解：

方法 1（最省事，足够实用）：两次仿真对比

- 跑全噪声得到 ((p_{\rm succ}^{\rm all},F^{\rm all}))；
- 跑 (p_{\rm dark}=0)（或关背景）得到 ((p_{\rm succ}^{\rm true},F^{\rm true}))。
  则
  [
  p_{\rm false}\approx p_{\rm succ}^{\rm all}-p_{\rm succ}^{\rm true},
  ]
  并且你能看到 (F) 的下拉幅度主要来自哪一项。

方法 2（更“严谨”，能直接给出假阳性样本）：在 Kraus 层标记“暗计数点击”
因为探测 POVM（含暗计数）本质是对角的，你可以选取一种 Kraus 分解，把“click”再细分成“dark-click”与“photon-click”两种 Kraus 分支（等价于在仿真里多记录一个标签变量）。然后 success set (\mathcal S) 内你就能统计“成功记录里暗计数占比/纯暗计数占比”，并分别得到 (\rho^{\rm true}*{AB|\rm succ})、(\rho^{\rm false}*{AB|\rm succ})。这会把差距写成：

# [ \bar\rho_{AB|\rm succ}

# \frac{p_{\rm true}\rho_{\rm true}+p_{\rm false}\rho_{\rm false}}{p_{\rm true}+p_{\rm false}}, \quad F_{\rm post}

\frac{p_{\rm true}F_{\rm true}+p_{\rm false}F_{\rm false}}{p_{\rm succ}}.
]

这对“指导实验提高保真度”非常直接：
如果 (p_{\rm false}/p_{\rm succ}) 已经很大，那么你提升干涉可见度带来的收益可能远小于“缩门宽、降暗计数、加滤波、降背景”带来的收益；反之亦然。

2.7 一个你可以立刻交付给实验的“最小可用输出包”

为了让你的仿真真正指导“怎么提高保真度”，我建议每组参数输出至少这 6 个量（它们都能由上面的计算得到，并且完全对齐你 spec 的输出目标与 success_patterns 的定义）：

- (p_{\rm succ})（总成功率）
- (F_{\rm post})（全噪声后验保真度）
- (p_{\rm succ}^{(p_{\rm dark}=0)})、(F_{\rm prior}^{\rm ideal})（理想化先验基线）
- (p_{\rm false}/p_{\rm succ})（假阳性占比，或至少用两次仿真差分近似出来）
- 以及随关键旋钮的曲线：门宽 (T_{\rm gate})、符合窗 (w)、暗计数 (p_{\rm dark})、QFC 噪声参数、偏振漂移强度（你现在 FiberChannelParams 里就有 polarization_sigma、eta_std、phase_drift_std 这些可扫参入口）。

这套输出比“跑到十几次成功轨迹”更能指导实验怎么改硬件与时序，而且计算量可控。

把话说得更直白一点：
你现在最应该追求的“最准”，不是“把实验的百万次失败都数值复现”，而是“在你的模型里，把 (\mathcal S) 上的 POVM 条件化算准、把漂移下的成功偏置平均算对、把假阳性占比拆清楚”。这三件事一旦做对，MPS 的价值就会非常具体：它不仅给 (F)，还告诉实验到底应该去降哪一种噪声、缩哪一种窗、以及哪一种改动对 (F) 的边际收益最大。
