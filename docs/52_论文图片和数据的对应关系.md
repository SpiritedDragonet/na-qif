## 0. 先统一两件关键事（避免你跑完找不到结果）

### 0.1 输出目录结构（server 模式）

你用 `--role server` 跑完（并确保 worker 把任务执行完 + summary 任务也执行完）后，结果在：

- **汇总 CSV**：
  `QUEUE_ROOT/RUN_ID/summary/*.csv`
- **每个核心任务的原始数据与图**：
  `QUEUE_ROOT/RUN_ID/results/result_<task_id>/raw/*`
  `QUEUE_ROOT/RUN_ID/results/result_<task_id>/plots/*`

> 你要画论文图，绝大多数直接用 `summary/xxx_summary.csv` 即可；少数“源端可视化”图需要 `plots/*.png` 或自定义导出（见下文）。

### 0.2 `--runs` 在不同 task 里的“计数口径”不一样（非常重要）

- **WINDOW_SCAN**：`runs` = 核心任务数量（每个 run 会产出 `shots` 条点击记录），summary 再对不同 window 做离线筛选。
  → 总样本量约 `runs × shots`。
- **HOM / BSM_SCAN / LENGTH_SCAN**：`runs` 是“每个扫参点”的 run 数。
  → 总任务量约 `(#sweep_points) × runs`，总样本量还要再乘 `shots`。

所以你说“总共大概 10000 次”，对于 HOM/长度扫描/BS 扫描，一般要把 `runs` 按 sweep 点数缩小，或者把 `shots` 做成主采样量。

建议你新建脚本 `export_bond_dim.py`（内容我给全），然后运行：

```bash
python .\export_bond_dim.py --out bond_dim.csv ^
```

`export_bond_dim.py` 参考实现（直接可用，按你现有模块结构做了最小依赖；若你的包名路径略有差别，把 import 的 `atom_sim...` 改成你工程里的实际包路径即可）：

```python
# export_bond_dim.py
import argparse, csv
from atom_sim.experiment.common import SimConfig, run_trial_physics_core

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--out", required=True)
    ap.add_argument("--fiber-length-km", type=float, default=16.5)
    ap.add_argument("--fiber-atten-db-per-km", type=float, default=0.2)
    ap.add_argument("--t2-us", type=float, default=330)
    ap.add_argument("--dark-hz", type=float, default=65)
    ap.add_argument("--eta-det", type=float, default=0.85)
    ap.add_argument("--v-res", type=float, default=0.955)
    ap.add_argument("--qfc-theta-h", type=float, default=0.856)
    ap.add_argument("--qfc-theta-v", type=float, default=0.856)
    ap.add_argument("--filter-cavity-fwhm-mhz", type=float, default=27)
    ap.add_argument("--filter-cavity-eta-peak-a", type=float, default=0.81)
    ap.add_argument("--filter-cavity-eta-peak-b", type=float, default=0.81)
    ap.add_argument("--qfc-noise-sd-cps-per-mhz-a", type=float, default=41.1)
    ap.add_argument("--qfc-noise-sd-cps-per-mhz-b", type=float, default=41.1)
    args = ap.parse_args()

    cfg = SimConfig()
    cfg.fiber.length_km = args.fiber_length_km
    cfg.fiber.attenuation_db_per_km = args.fiber_atten_db_per_km
    cfg.run.t2_us = args.t2_us
    cfg.noise.dark_rate_intrinsic_hz = args.dark_hz
    cfg.detector.eta_det = args.eta_det
    cfg.detector.v_res = args.v_res
    cfg.qfc.theta_h = args.qfc_theta_h
    cfg.qfc.theta_v = args.qfc_theta_v
    cfg.filter_cavity.fwhm_mhz = args.filter_cavity_fwhm_mhz
    cfg.filter_cavity.eta_peak_a = args.filter_cavity_eta_peak_a
    cfg.filter_cavity.eta_peak_b = args.filter_cavity_eta_peak_b
    cfg.qfc.noise_sd_cps_per_mhz_a = args.qfc_noise_sd_cps_per_mhz_a
    cfg.qfc.noise_sd_cps_per_mhz_b = args.qfc_noise_sd_cps_per_mhz_b

    pipe = run_trial_physics_core(cfg, seed=12345, hooks=None)
    # 注意：pipe.emission.mps 是“通过到 BS 之后”的状态；如果你只想看“发射后”的 chi，
    # 需要在 run_trial_physics_core 内部挂 hook，或改成只跑 emission pipeline。
    mps = pipe.emission.mps
    chi = mps.get_bond_dimensions()

    with open(args.out, "w", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        w.writerow(["bond_index", "chi"])
        for i, v in enumerate(chi):
            w.writerow([i, int(v)])

if __name__ == "__main__":
    main()
```

### 2.4 画图取列

- CSV：`bond_dim.csv`
- x：`bond_index`
- y：`chi`

### 2.5 NeurIPS 级别画法建议

- **强烈建议 2D**：`chi` 随 bond_index 的折线图（或半对数），并叠加 `chi_max=50` 的水平线，清晰表达“截断余量”。
- 若你想把它解释为“随时间 bin 演化”，应把 bond_index 映射到 time-bin index（这需要你明确 MPS site 排列规则，并在图注里写清映射）。

- `V = (C_max - C_min)/C_max`

### 1) 所有 scan summary 里的 `p_success_true_given_arrival_global` 口径是错的

[

对应代码是类似这一段（以 length_scan 为例）：


但没输出。建议增加一个**非常轻量**的输出文件（每个 run 一份即可）：

- `raw/declared_density_matrix.json`
  - `rho_raw = sigma_declared_raw / trace(sigma_declared_raw)`
  - `rho_ff = sigma_declared_ff / trace(sigma_declared_ff)`

或者写成 CSV：

- `declared_density_matrix.csv`，列为：
  - `run_index, variant(raw/ff), i, j, real, imag`

然后在 summary 端再额外输出一个“跨 runs 的平均密度矩阵”：

- `declared_density_matrix_mean.csv`

图形层面：严格来说 NeurIPS 更偏好 2D heatmap（Real/Imag 两张），3D bar 往往信息密度低且难读；但你 thesis 可以保留 3D，投稿时换成 2D。NeurIPS 的排版规范也强调图要可读、字号要足够大、优先矢量图等。([NeurIPS Media](https://media.neurips.cc/Conferences/NeurIPS2022/Styles/neurips_2022.pdf))

### G. 统计学层面的 NeurIPS 要求

你 scan summary（window/length/bsm）目前只给平均值，没有给方差、置信区间。NeurIPS 级别的呈现通常需要至少：

- `*_std`
- `*_stderr`（或 95% CI）

建议在 `*_summary.csv` 里对以下关键量输出 `avg/std/stderr` 三件套：

- `p_success_abs`
- `p_success_true_abs`
- `p_success_false_abs`
- `fidelity_true`
- `false_fraction`
- `chsh_s_max`
- `event_rate_hz`

> CHSH 的 S_\max 你已经按 Horodecki 公式算了（这是标准最大违背量），给出 error bar 会更有说服力。([Astrophysics Data System](https://ui.adsabs.harvard.edu/abs/1995PhLA..200..340H/abstract))

  但这不是必须。

## 面向论文作图的几个关键建议

### HOM 图的口径要明确

HOM visibility 常用定义是：
[
V = \frac{C_{\max}-C_{\min}}{C_{\max}}
]
（或用 ((C_{\max}-C_{\min})/(C_{\max}+C_{\min})) 的变体，需要你在文中明确）。([arXiv](https://arxiv.org/pdf/2201.04549))

你现在 `hom_summary.csv` 给的是 `coinc_rate`，可以直接用它拟合 dip，并从拟合提取 (V)。建议你在 summary 里额外输出：

- `coinc_rate_std / coinc_rate_stderr`（跨 runs）
- `coinc_rate_true`（你已经输出了 true/dark 分解，非常好）
