你现在抓到的点是对的：**电信波段光纤对“偏振 qubit”的主要作用，本质就是一个随时间漂移的 Jones 变换（2×2 复矩阵）+ 损耗**；在布洛赫球（更准确说是 Poincaré 球/Stokes 球）上看，就是一个随时间缓慢变化的旋转。实验里靠**偏振控制器（PC）闭环**把这个旋转“拉回”到指定基矢；如果拉不回或拉得不够准，就会直接表现为**中站两光子干涉对比度下降、BSM 误触发比例上升、最终条件态保真度下降**。

下面我按“**哪些噪声值得建、如何把它们写成门/矩阵、如何把 PC 的不完全纠正放进去，并且能随着 PC 参数变化出现不同效果**”来给你一个能直接落到你现在 time-bin + MPS/TEBD 框架里的方案（并尽量对齐你已有的大图纸与流水表结构 ）。

## 1) 光纤里“会动的”到底是什么：把噪声按物理效果分成 6 类

对你这种“telecom 单光子 + 中站 BS 干涉/BSM”的任务，建议把“光纤传播噪声/震动”按它们对**波包可区分性**的影响来建模：

### A. 衰减与插损（Loss）

- **效果**：降低真光子到达率；在有暗计数/背景时，会提高“假成功”占比。
- **数值模型**：幅度阻尼（beamsplitter-to-vacuum）Kraus。你的 spec 里已经把“单模式 n≤2 截断时的 Kraus 嵌入规则”写得很机械化了（K0/K1/K2） 。

### B. 偏振漂移（SOP drift，Jones 漂移）

- **物理来源**：温度、应力、振动引起的随机双折射变化。
- **效果**：光子的偏振态在 Poincaré 球上随机转；两臂到达中站的偏振不再对齐 → 干涉可见度掉。
- **数值模型**：每条臂一个随时间变化的 **2×2 Jones 矩阵** (J_A(t), J_B(t))（近似无 PDL 时可写成 (J=\sqrt{\eta},U,,U\in SU(2))）。

> 这就是你说的“布洛赫球漂移”。

### C. 偏振相关损耗（PDL）

- **效果**：不是纯旋转了，而是不同偏振透过率不同 → 纠缠态的振幅比被拉歪，PC 也没法“用纯旋转”完全修复。
- **数值模型**：在某个偏振基（通常是 PSP 或器件本征轴）上给不同的 (\eta_1,\eta_2)，用**两个偏振模式各自的损耗 Kraus**实现（或先旋到 PSP 再做两通道损耗）。

### D. PMD（Polarization Mode Dispersion）

- **效果**：Jones 变换对频率 (\omega) 依赖，等价于“两个主偏振态 PSP 的群时延不同”；在时域会把偏振与到达时间纠缠起来 → 造成跨 time-bin 的混合/移位。
- **数值模型**（你们图纸已定版）：PSP 基变换 + PSP2 分量跨 bin 的 SWAP 移位网络 + 逆变换 。

### E. 相对到达时延/抖动（timing offset/jitter）

- **来源**：光纤长度变化、同步误差、电子/触发延迟变化。
- **效果**：两光子波包时间重叠下降 → HOM/BSM 对比度掉。
- **实验事实**：van Leent 等的系统把两节点同步做到 <300 ps，而光子相干时间 ~26.2 ns；而数据评估里会用 ~70 ns 接受窗（再加硬件 coincidence window） 。
- **数值模型**：最省力的是“相对 bin 平移”：
  - 方案 A：直接把 B 臂的发射包络 (\gamma_B[n]) 平移 `delta_bins`（你的 spec 已明确这是推荐且不需要造 10^5 个真空 bin） 。
  - 方案 B：用 delay-line SWAP 置换网络把 telecom 模式在 bin 序列上整体移动（更通用，也在 spec 里写了） 。

### F. 背景/暗计数（严格说不是光纤本体，但和“长光纤低信号”强耦合）

- **效果**：假符合会把 (p_{\rm succ}) 撑起来、把条件态保真度拉下来。
- **数值模型**：探测 POVM/Kraus + 暗计数参数；你们“按成功事件集合 (\mathcal S) 条件化”的处理方式也写得很清楚，尤其强调**漂移外参下要用 (p_{\rm succ}(x)) 加权平均** 。

## 2) 真正“指导实验”的关键：把时间尺度分开（否则你会把算力花在无意义的快噪声上）

你现在担心的“震动/漂移”很容易被误建成“每个 time-bin 都完全独立随机”，但真实里往往不是：

- **单个 entanglement try（ns–µs 级）内**：光纤 SOP 基本可以视作常量（除非你真的在做极端高速扰动）。
- **分钟级**：SOP 会漂移，需要 PC 重锁。
- **你要仿真的正确结构**应该是：
  **外层慢时间**（漂移与 PC 更新）× **内层快时间**（time-bin/MPS 演化）。

这也和 Nature 实验的描述吻合：他们用自动偏振控制补偿长光纤漂移，**每 7 min 做一次控制**，平均耗时 20 s，用梯度下降算法；用 V 与 D 两种参考偏振、10 Hz 交替；并且在 BSM 的光纤 BS 处放了 3 个 PC（两输入一输出），把偏振误差压到 <1% 。

## 3) 在你的 time-bin/MPS 流水线里，光纤偏振/漂移应该怎么写成“门与矩阵”

你们的总体流水线结构已经把“光纤偏振演化与 PMD”明确成一个模块，位置在损耗/噪声之后、BSM 之前 。实现上建议拆成三段：

### 3.1 损耗 / PDL：one-site Kraus（telecom 模式上）

- 若你 bin 采用 15 维 “四模 Fock 总光子数 ≤2”的闭合截断（强烈推荐），则每个 mode 的损耗 Kraus 你可以按 spec 里的嵌入规则构造（K0/K1/K2） 。
- PDL 就是对 `c_H`、`c_V` 用不同 (\eta_H,\eta_V)（或先旋到 PSP 再做）。

> 重要提醒：你们文档已经强调过：**做 BS 干涉必须让局域空间容纳两光子 sector**，否则 HOM bunching 会“跑出截断空间”导致成功率/统计系统性错误 。所以如果你还在用 5 维单光子压缩基，偏振漂移建得再精细也不够“可定量指导”。

### 3.2 Jones 旋转：one-site unitary（telecom 子空间上）

你要的是把一个 2×2 Jones 矩阵 (U)（作用在 ((c_H,c_V)) 上）提升到“Fock 截断空间”的幺正门 (U_{\rm pol})。

两种实现都可行：

#### 实现法 A：二次型生成元（推荐，最稳）

你们 spec 里给的做法是：

1. 取 (J\in SU(2))（或从测量/模型得到的 Jones），求 (K = i\log(J))（并可取 Hermitian 部分稳定数值）。
2. 构造
   [
   H_{\rm pol}=\sum_{p,q\in{H,V}} K_{pq},c_p^\dagger c_q
   ]
3. 得到 one-site 门
   [
   U_{\rm pol}=\exp(-i H_{\rm pol})
   ]
   这会自动正确处理 0/1/2 光子 sector，并保持 bosonic 对称性 。

#### 实现法 B：显式在 0/1/2 sector 写出矩阵（便于你 debug）

对 telecom 的 0/1/2 光子 sector：

- Vacuum：不动
- 单光子：就是 2×2 的 (U)
- 双光子对称基 ({|HH\rangle,|HV\rangle,|VV\rangle})：用“creation operator 线性变换”推出来：
  - 令
    [
    \begin{pmatrix}a_H^\dagger\a_V^\dagger\end{pmatrix}\to
    U\begin{pmatrix}a_H^\dagger\a_V^\dagger\end{pmatrix}
    ]
  - 则
    [
    |HH\rangle \to U_{HH}^2|HH\rangle+\sqrt2U_{HH}U_{HV}|HV\rangle+U_{HV}^2|VV\rangle
    ]
    [
    |HV\rangle \to \sqrt2U_{HH}U_{VH}|HH\rangle+(U_{HH}U_{VV}+U_{HV}U_{VH})|HV\rangle+\sqrt2U_{HV}U_{VV}|VV\rangle
    ]
    [
    |VV\rangle \to U_{VH}^2|HH\rangle+\sqrt2U_{VH}U_{VV}|HV\rangle+U_{VV}^2|VV\rangle
    ]
    把这个 3×3 填进你的 bin 总基里即可。

### 3.3 PMD：跨 bin 的 SWAP 网络（PSP2 移位）

你们“总设计图纸”和 spec 都把 PMD 明确为：

- 每个 bin：(R_{\rm in}) 把 H/V 旋到 PSP1/PSP2
- SWAP 链把 PSP2 分量延迟/提前 m 个 bin（整数版最先落地）
- 每个 bin：(R_{\rm out}) 旋回 H/V

这就是你要的“偏移算法”：它不是玄学，就是**置换/移位门**（置换矩阵/局域 SWAP 两体门序列）。

## 4) 你最关心的：偏振控制器（锁相/闭环）怎么仿？要不要仿“不完全纠正”？

### 4.1 先给结论：要不要仿不完全纠正，取决于你想回答哪个实验问题

- 如果你的目标是复现 van Leent 这类“偏振误差 <1%”的理想锁定极限，那么你可以把 PC 当作“完美把 Jones 拉回目标”的理想门（即 (U_{\rm PC}\approx U_{\rm fiber}^{-1})），只留一个很小的残差角度做扫描。因为他们确实用自动控制把误差压到 1% 量级 。
- 如果你的目标是“**指导实验该怎么设控制周期、控制带宽、参考光功率/测量噪声、以及 PC 误差对最终 F 的灵敏度**”，那就非常值得仿“不完全纠正”，而且你会得到很直接的工程结论：
  - 漂移越快 / 更新越慢 → 残差越大 → 干涉对比度越低 → (F) 下滑
  - 反过来你能算出“为了把 (F) 保持 > 某阈值，PC 残差角度要 < 多少度 / 更新周期要 < 多少秒”。

### 4.2 “最小但真实”的 PC 建模：把闭环效果压缩成一个残差 SU(2)（推荐先做这个）

你不必一上来把真实 PC 的每个波片机械角都仿出来。对“对真实试验有指导价值”的第一步，最有用的是把“闭环后没纠正干净的那一点”显式变成参数：

- 光纤真实 Jones：(U_{\rm fiber}(t))
- 控制器设定出来的补偿：(U_{\rm PC}(t))
- 残差（你关心的）：
  [
  U_{\rm res}(t)=U_{\rm PC}(t),U_{\rm fiber}(t)
  ]
  理想情况下 (U_{\rm res}=I)。

**仿不完全纠正**最简单的方法就是直接设：
[
U_{\rm res}(t)=\exp!\left(-\frac{i}{2},\boldsymbol\epsilon(t)\cdot\boldsymbol\sigma\right),
\quad
\boldsymbol\epsilon\sim \mathcal N(0,\sigma_{\rm res}^2 I)
]

- (\sigma_{\rm res}) 就是一根“控制器性能旋钮”：越小代表锁得越好。
- 你还可以让它随“距上次重锁的时间”增长，例如
  [
  \sigma_{\rm res}^2(\Delta T)=\sigma_0^2 + 2D,\Delta T
  ]
  这里 (D) 是漂移扩散系数，(\Delta T) 是距离上次校准的时间。

**怎么把它放进你现有门序列？**
就当作在 BSM 前对每个 bin 加一个 one-site 的 (U_{\rm pol}=U_{\rm res}) 门（或把它并入 (J_A,J_B) 的总 Jones 门里），完全符合你们流水表“损耗后→Jones→BSM”的位置 。

> 这样你就能非常直观地扫参：(\sigma_{\rm res}) 从 0 到 0.3 rad（几度到十几度），看 (p_{\rm succ}) 与 (F) 怎么变——这对实验端是“可操作”的。

### 4.3 想让“随着 PC 调整参数变化呈现不同效果”：把 PC 写成可调的 3 参数 SU(2) 并加上梯度下降闭环

如果你确实想把“PC 的调整情况参数”当作输入（例如三个 paddle 角度），那就做一个“**PC = 可调 SU(2)**”的参数化，并在慢时间上跑一个优化：

#### (a) 参数化（你可以用 Euler 角，或 QWP-HWP-QWP）

一个通用可调 SU(2)：
[
U_{\rm PC}(\alpha,\beta,\gamma)=e^{-i\alpha\sigma_z/2},e^{-i\beta\sigma_y/2},e^{-i\gamma\sigma_z/2}
]
（对应“3 个自由度能覆盖任意偏振旋转”的事实。）

#### (b) 代价函数（和实验做法一致：用两种参考偏振）

Nature 实验用两种线偏振参考：Vertical 与 Diagonal，并用梯度下降优化 。你数值里可以完全照抄这个结构：

- 参考输入态：(|V\rangle, |D\rangle)
- 目标输出态（你想锁到的 SOP）：通常就是让输出仍是 (|V\rangle,|D\rangle)（或某个固定基）
- 定义输出：
  [
  |\psi_{\rm out}\rangle = U_{\rm PC}(\theta),U_{\rm fiber}(t),|\psi_{\rm in}\rangle
  ]
- 代价函数（例）：
  [
  C(\theta)=1-|\langle V|\psi_{\rm out}(V)\rangle|^2 ;+; 1-|\langle D|\psi_{\rm out}(D)\rangle|^2
  ]
  或者用 Stokes 向量误差也行（更像 polarimeter）。

#### (c) 梯度下降更新（慢时间步长）

[
\theta \leftarrow \theta - g \nabla_\theta C(\theta)
]

- 你可以用数值差分算梯度（最省事），再加上：
  - **测量噪声**（模拟 polarimeter/光功率有限）
  - **执行器分辨率**（角度量化到步进）
  - **延迟**（控制器更新滞后，模拟 7 min 才重锁一次）

这会自然地产生“纠正不完全”的残差，而且残差大小会随 (g)、噪声、量化、更新周期等参数变化——这就是你要的“随着 PC 参数变化呈现不同效果”。

## 5) 让仿真“对真实试验有指导价值”的两个关键输出：不要只看 Jones 本身

最后我建议你把“偏振漂移/PC”的效果转成实验真正关心的两个量，并且和你现在的后处理框架对齐：

### 5.1 把偏振误差映射到“干涉不可区分性/对比度”

中站两光子干涉主要吃的是两光子内部态重叠（这里内部态 = 偏振+时间模式）。偏振这块最直接的指标是相对 Jones：
[
U_{\rm rel}(t)=U_{A,\rm eff}^\dagger(t),U_{B,\rm eff}(t)
]
当 (U_{\rm rel}=I) 时偏振完全匹配。

你可以输出一个“残差角度”：

- 把 (U_{\rm rel}) 写成轴角：(U_{\rm rel}=\exp(-i\delta,\hat n\cdot\sigma/2))
- (\delta) 就是两臂 SOP 的相对失配角

这比直接看矩阵元素更“工程可读”。

### 5.2 慢漂移下的正确平均方式：按成功率加权

你们“如何处理得到结果”的文档已经强调：在慢漂移外参 (x) 下，实验看到的成功后条件态不是简单平均，而是
[
\bar\rho_{AB|\rm succ}=\frac{\mathbb E_x[p_{\rm succ}(x),\rho_{AB|\rm succ}(x)]}{\mathbb E_x[p_{\rm succ}(x)]}
]
否则会把“成功偏置”平均错掉 。

这点在“偏振漂移 + PC 纠正不完全”时尤其重要：因为某些 SOP 状态下更容易触发成功/假成功，后验样本会偏。
