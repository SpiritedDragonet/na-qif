Q:我要做出两路的单光子波包的图像，用什么数据能画出每一路N个bin（准备给N指定它个200左右）连起来每个bin上的该光子概率（不知道我说的是不是单光子波包的画法）

A:你说的就是“单光子波包的画法”，只不过要把“波包”在 time-bin 离散化下对应成一串数：对每个时间片/bin (n)，算“光子在这个 bin 里的概率（或强度）”。

在你的 time-bin MPS 里，最直接可画的两类数据是：

1. 强度包络（photon flux/intensity）
   [
   p_n \equiv \langle \hat N_n\rangle
   ]
   它表示第 (n) 个 bin 里“平均有多少个（电信段）光子”。如果理想情况下每臂只有单光子、且每个 bin 不会有两光子，那么 (p_n \approx \Pr(\text{光子在 bin }n))。

2. “单光子概率”包络（更严格，适合你保留了两光子扇区）
   [
   q_n \equiv \Pr(\text{该 bin 恰好有 1 个电信光子})=\langle \Pi^{(1)}_n\rangle
   ]
   其中 (\Pi^{(1)}_n) 是投影到 (|1H\rangle,|1V\rangle) 子空间的投影算符。
   因为你 1517nm 本地空间允许 (|2H\rangle,|2V\rangle,|HV\rangle)，所以 **用 (\langle \hat N\rangle) 画出来的不是“概率”而是“平均光子数”**；若你想画“单光子波包”就用 (q_n) 更合适。

下面按你给的基序，告诉你每个 bin 上到底该算什么、怎么从 MPS 里拿出来。

---

## 1) 你 1517nm 六维基上的投影/数算符

你说 1517nm 的 6 维基序是：

[
[\text{vac},,1H,,1V,,2H,,2V,,HV]
]

那么：

* 单光子投影（不区分 H/V）
  [
  \Pi^{(1)}_{1517}=\mathrm{diag}(0,1,1,0,0,0)
  ]

* H/V 单光子投影（分别画两条也行）
  [
  \Pi^{(1H)}*{1517}=\mathrm{diag}(0,1,0,0,0,0),\quad
  \Pi^{(1V)}*{1517}=\mathrm{diag}(0,0,1,0,0,0)
  ]

* 电信段总光子数算符（画强度用）
  [
  N_{1517}=\mathrm{diag}(0,1,1,2,2,2)
  ]
  以及按偏振分解的
  [
  N_{H,1517}=\mathrm{diag}(0,1,0,2,0,1),\quad
  N_{V,1517}=\mathrm{diag}(0,0,1,0,2,1)
  ]

---

## 2) 把它嵌入到你 bin 的 18 维（780×1517）空间

你说 bin 是 780(3)×1517(6)=18 维。假设你的扁平化顺序是：

[
|i_{780}\rangle\otimes|j_{1517}\rangle,\quad \text{flatten index}=i_{780}\cdot 6+j_{1517}
]

那电信段算符在 18 维上的嵌入就是：

[
\Pi^{(1)}*{\rm bin}=I*{780}\otimes \Pi^{(1)}*{1517},\quad
N*{\rm bin}=I_{780}\otimes N_{1517}.
]

（如果你实际用的是反过来的 flatten 顺序，就把 Kronecker 顺序对调一下。）

---

## 3) 你要画的“每一路 N 个 bin 的概率曲线”就是两条数组

对 A 臂：`qA[n]` 或 `pA[n]`
对 B 臂：`qB[n]` 或 `pB[n]`

其中（推荐画单光子概率）：
[
qA_n=\mathrm{Tr}(\rho_{A_n},\Pi^{(1)}*{\rm bin}),\quad
qB_n=\mathrm{Tr}(\rho*{B_n},\Pi^{(1)}*{\rm bin})
]
(\rho*{A_n}) 是第 (n) 个 A-bin 的单站点约化密度矩阵。

你用 TeNPy 最稳的方式是直接调用：

* `rho = psi.get_rho_segment([idx])` 得到该站点的约化密度矩阵（npc.Array），再 `to_ndarray()`。

---

## 4) 最小可用代码骨架（画两条波包）

假设你的站点排列是：
`atomA, atomB, A1, B1, A2, B2, ..., AN, BN`
则 A_n 的 index 是 `2 + 2*(n-1)`，B_n 是 `3 + 2*(n-1)`。

```python
import numpy as np
import matplotlib.pyplot as plt

def telecom_ops_bin18():
    I780 = np.eye(3)
    # 1517 basis: [vac,1H,1V,2H,2V,HV]
    P1_1517 = np.diag([0,1,1,0,0,0])
    N_1517  = np.diag([0,1,1,2,2,2])

    P1_bin = np.kron(I780, P1_1517)  # 18x18
    N_bin  = np.kron(I780, N_1517)   # 18x18
    return P1_bin, N_bin

def wavepacket_from_mps(psi, N, use_single_photon_prob=True):
    P1_bin, N_bin = telecom_ops_bin18()
    qA = np.zeros(N)
    qB = np.zeros(N)

    for n in range(1, N+1):
        idxA = 2 + 2*(n-1)
        idxB = 3 + 2*(n-1)

        rhoA = psi.get_rho_segment([idxA]).to_ndarray()  # 18x18
        rhoB = psi.get_rho_segment([idxB]).to_ndarray()

        Op = P1_bin if use_single_photon_prob else N_bin
        qA[n-1] = float(np.real(np.trace(rhoA @ Op)))
        qB[n-1] = float(np.real(np.trace(rhoB @ Op)))

    # 如果你想画“条件波包形状”（给定确实发出了一个光子），做归一化：
    # qA /= (qA.sum() + 1e-15)
    # qB /= (qB.sum() + 1e-15)

    return qA, qB

# 用法：
# qA, qB = wavepacket_from_mps(mps_state._mps, N=200, use_single_photon_prob=True)
# t = np.arange(200)  # 或者 t = np.arange(200) * dt
# plt.plot(t, qA, label="Arm A")
# plt.plot(t, qB, label="Arm B")
# plt.legend(); plt.show()
```

你可以画三种版本（建议都试一下，帮助诊断）：

* `use_single_photon_prob=True`：严格的“单光子波包概率”
* `use_single_photon_prob=False`：强度 (\langle N\rangle)（若出现两光子，这条会高于 1-photon 概率）
* 把 `qA,qB` 归一化后画“形状”（不受总发射概率影响）

## 5) 两个容易踩坑的现实提醒

1. 你要在“合适的时刻”取这条波包
   如果你在中站已经做了测量（Kraus/POVM 条件化），那波包会被投影/塌缩，画出来的是“测量后的残态分布”，往往不代表入射波包。
   通常你想画的是“进入中站干涉之前”的入射波包：也就是在 BS 门之前取 `rho_{A_n}, rho_{B_n}`。

2. 你现在是轨迹法（Kraus 抽样）的话，单条轨迹的波包会有随机性
   想要一条“平滑、代表物理期望”的波包曲线，通常要：

* 关掉随机噪声先看无噪声波包；或
* 跑很多条轨迹，对 (q_n) 做平均（以及给误差条）。
