下面给出你要的“**逐行流水表**”：把我们定版模型的各个模块（源端发射含偏振映射、QFC、滤波记忆、损耗/噪声、光纤偏振演化与 PMD、中站 BS 干涉与探测条件化）**严格按程序执行顺序**写成一条可以直接照着实现的算法时序，并明确每一步是 **one-site gate / two-site gate / Kraus / SWAP / 跨 bin 网络**中的哪一种，以及作用在哪些站点上。整个流程仍以 **MPS（TEBD/TDVP）+（可选）量子轨迹**为骨架。

------

## 0. 你真正要落地的对象：一次尝试的“时序—门—测量”流水线

一次链路尝试（一个探测门宽内的所有 time-bins）对应一次数值实验。你要输出的“最终产物”在程序上可以固定为：

- 成功概率：(p_{\mathrm{succ}}=\Pr(\mathbf{r}_{1:N}\in\mathcal{S}))
- 条件原子态：(\rho_{AB|\mathrm{succ}})
- 条件保真度：(F=\langle\Phi_{\mathrm{target}}|\rho_{AB|\mathrm{succ}}|\Phi_{\mathrm{target}}\rangle)

其中 (\mathbf{r}_n) 是第 (n) 个 bin 的 4 个探测器点击向量（或你定义的探测器集合），(\mathcal{S}) 是“成功点击模式集合”。

------

## 1. 站点排列：保证所有关键物理操作都是局域门

### 1.1 MPS 站点顺序（推荐固定为这一种）

[
\boxed{
S ;-; A_1 ;-; B_1 ;-; A_2 ;-; B_2 ;-; \cdots ;-; A_N ;-; B_N
}
]

- (S)：system 复合站点（两原子 + 可选滤波腔/内部模式 + 其它需要“记忆”的局域自由度）
- (A_n)：A 臂第 (n) 个 time-bin 场站点
- (B_n)：B 臂第 (n) 个 time-bin 场站点

**关键点：**

- 中站 BS 干涉发生在同一 (n) 的 (A_n) 与 (B_n)，它们在链上天然相邻，适合 two-site gate。
- 源端发射/滤波是 (S) 与当前 bin 的耦合，需要让 (S) 依次邻接 (A_n) 与 (B_n)，用 SWAP“传送带”实现。

------

## 2. 局域基与截断：保证“BS + 探测”在你选的局域空间内闭合

你这次明确强调偏振必须严肃建模，而两光子符合（partial BSM）必然涉及 **两光子干涉**。因此有一个实现上必须先“写死”的事实：

> 如果你在每条臂每个 bin 上只保留“0/1 光子”，那么在对 (A_n,B_n) 施加 50/50 BS 后，(|1\rangle_A|1\rangle_B) 会产生“bunching”的 (|2\rangle) 输出分量；如果你的局域空间里没有 (|2\rangle) 相关状态，BS 门就不闭合，HOM/BSM 概率会算错。

因此，**面向可实施的最小闭合截断**建议如下（二选一，你只需选一种并保持一致）：

### 方案 I（更直观、便于分块）：每臂每 bin 采用“(780 两偏振)×(1517 两偏振)”四模 Fock，限制总光子数 (\le 2)

- 模式：((b_H,b_V,c_H,c_V))（(b)=780, (c)=1517）
- 局域 Hilbert 空间：(\mathcal{H}*{\mathrm{bin}}=\mathrm{span}{|n*{bH},n_{bV},n_{cH},n_{cV}\rangle: n_{\mathrm{tot}}\le2})
- 维度：
  (n_{\mathrm{tot}}=0:1), (n_{\mathrm{tot}}=1:4), (n_{\mathrm{tot}}=2:\binom{2+4-1}{4-1}=10)，总计 (1+4+10=15)。
  所以每个 (A_n) 或 (B_n) 是 15 维。

这个方案能自然覆盖：

- 单光子信号（总数 1）
- 两臂同时到达（总数 2）
- 一点点“一噪声光子 + 一信号光子”的情形（仍在总数 2 内）

### 方案 II（更工程化拆分）：780 只保留 0/1，1517 保留到 2（总维度 18）

- 780 子空间（H/V）：({|0\rangle,|H\rangle,|V\rangle})（3 维）
- 1517 子空间（H/V，允许两光子）：({|0\rangle,|H\rangle,|V\rangle,|HH\rangle,|HV\rangle,|VV\rangle})（6 维）
- 总维度：(3\times 6 = 18)

两者都可实现；我在下面的流水表里用**抽象记号**写门的作用，与你选 15 维或 18 维不冲突，只要你保证 BS/探测那部分允许两光子即可。

------

## 3. 门库：把所有模块先写成“可调用的门/信道对象”

为了让流水表不重复堆公式，先定义你在程序里要有的一组“门工厂”对象（数学上就是矩阵或 Kraus 集）：

### 3.1 源端发射门（含偏振映射）(U^{\mathrm{emit}}_{j,n}) ：two-site unitary on ((S, j_n))

对 (j\in{A,B})：

- 原子辐射通道（(\sigma^\pm)）：
  [
  S_{j,+}=|0\rangle_j\langle e|,\quad S_{j,-}=|1\rangle_j\langle e|
  ]
- 几何/收集/偏振定义压缩成矩阵 (\Alpha^{(\mathrm{emit})})（从 (\sigma^\pm) 到数值偏振基 (p\in{H,V})）：
  [
  \Alpha^{(\mathrm{emit})}
  =
  \begin{pmatrix}
  \alpha_{H,+} & \alpha_{H,-}\
  \alpha_{V,+} & \alpha_{V,-}
  \end{pmatrix}
  ]
- 耦合算符：
  [
  L_{j,p}(t_n)=\sqrt{\gamma_j(t_n)}\Big(\alpha_{p,+}S_{j,+}+\alpha_{p,-}S_{j,-}\Big)
  ]
- time-bin 离散门：
  [
  \boxed{
  U^{(\mathrm{emit})}*{j,n}
  =
  \exp!\left[
  \sqrt{\Delta t}\sum*{p\in{H,V}}
  \Big(
  L_{j,p}(t_n), b^{p\dagger}_{j,n}
- 

L^\dagger_{j,p}(t_n), b^{p}_{j,n}
\Big)
\right]
}
]

> 这一步就是把“原子核自旋态与光子偏振纠缠”严格写进演化里；你担心的偏振问题本质上都体现在 (\Alpha^{(\mathrm{emit})}) 的结构与后续 Jones/PMD 的作用上。

------

### 3.2 QFC 门 (U^{\mathrm{QFC}}_{j,n})：one-site unitary on (j_n)（同一站点内部 b↔c 耦合）

# 对每偏振 (p)： [ \boxed{ U^{(\mathrm{QFC})}_{j,n}

\exp!\left[
-i\sum_{p\in{H,V}}
\theta_p\Big(
b^{p}*{j,n}c^{p\dagger}*{j,n}+b^{p\dagger}*{j,n}c^{p}*{j,n}
\Big)
\right]
}
]

------

### 3.3 滤波/窄带腔（记忆）门 (U^{\mathrm{filt}}_{j,n})：two-site unitary on ((S, j_n))（若你把滤波腔并入 S）

## 示意（对每偏振一份）： [ U^{(\mathrm{filt})}*{j,n} \approx \exp!\left[ \sqrt{\Delta t}\sum*{p} \Big( \sqrt{\kappa_f},a_{j,p},c^{p\dagger}_{j,n}

\sqrt{\kappa_f},a^\dagger_{j,p},c^{p}*{j,n}
\Big)
\right]
\cdot e^{-iH*{f}\Delta t/\hbar}
]
(a_{j,p}) 是滤波腔内部模（在 (S) 里），(H_f=\hbar\Delta_f a^\dagger a)。

------

### 3.4 损耗/PDL/器件损耗：Kraus(one-site) on (j_n)

典型幅度阻尼（单模式）：
[
K_0=|0\rangle\langle0|+\sqrt{\eta}|1\rangle\langle1|+\eta|2\rangle\langle2|+\cdots
]
[
K_1=\sqrt{1-\eta},|0\rangle\langle1|+\sqrt{2\eta(1-\eta)},|1\rangle\langle2|+\cdots
]
（多光子截断下可以写到你保留的最高占据。）

PDL 就用不同偏振 (\eta_H,\eta_V)。

------

### 3.5 偏振 Jones 旋转 (U^{\mathrm{pol}}_{j})：one-site unitary on telecom 模式子空间

[
\boxed{
\begin{pmatrix}c^{H}*{j,n}\c^{V}*{j,n}\end{pmatrix}
\longrightarrow
U_{j}
\begin{pmatrix}c^{H}*{j,n}\c^{V}*{j,n}\end{pmatrix},
\quad U_j\in SU(2)
}
]

------

### 3.6 PMD：跨 bin 的“PSP 基 + 移位网络 + 逆变换”(\mathcal{U}^{\mathrm{PMD}}_j)

设 (m=\mathrm{round}(\Delta\tau/\Delta t))：

1. 每个 bin 做 (R_{\rm in})：(H/V\to\mathrm{PSP})（one-site）
2. 对 (\mathrm{PSP}_2) 分量做移位 (m) 个 bin：用最近邻 SWAP 链（two-site 序列）
3. 每个 bin 做 (R_{\rm out})（one-site）

（下面 §6 给你一个“可直接照抄”的 PMD 子程序流水。）

------

### 3.7 中站 50/50 BS 干涉 (U^{\mathrm{BS}}_n)：two-site unitary on ((A_n,B_n))

# 对每偏振 (p)： [ \boxed{ \begin{pmatrix} d^{p}*{1,n}\ d^{p}*{2,n} \end{pmatrix}

\frac{1}{\sqrt{2}}
\begin{pmatrix}
1 & 1\
1 & -1
\end{pmatrix}
\begin{pmatrix}
c^{p}*{A,n}\
c^{p}*{B,n}
\end{pmatrix}
}
]
把这作为一个作用在两站点 telecom 子空间上的幺正门即可（要求你的截断能容纳两光子）。

------

### 3.8 探测 Kraus：作用在 ((A_n,B_n)) 的（通常可分解为四个输出模的）对角 Kraus

对每个探测器模式 (q)（例如 (q\in{(1,H),(1,V),(2,H),(2,V)})），给定效率 (\eta_d)、暗计数 (p_{\rm dc})，on/off POVM 元素可以写为：

- no-click（对角）：
  [
  E^{(q)}*0=\sum*{m\ge0}(1-p_{\rm dc})(1-\eta_d)^m,|m\rangle\langle m|
  ]
- click：
  [
  E^{(q)}_1=I-E^{(q)}_0
  ]

对整体点击模式 (\mathbf{r}*n)：
[
E*{\mathbf{r}*n}=\bigotimes_q E^{(q)}*{r_{n,q}}
]
轨迹法中可取 Kraus (M_{\mathbf{r}*n}=\sqrt{E*{\mathbf{r}_n}})（仍是对角）。

------

### 3.9 system 噪声：原子退相干/自发散射等（one-site Kraus on (S)）

例如纯退相干（示意）：
[
\mathcal{E}*{\phi}(\Delta t):\quad
\rho\mapsto (1-p*\phi)\rho + p_\phi, Z\rho Z
]
或用连续形式 (p_\phi\approx \gamma_\phi\Delta t)。

------

## 4. “传送带”核心：让 (S) 依次作用到 (A_n)、(B_n)，再回到下一步

定义相邻站点 SWAP 门：
[
\mathcal{S}*{k,k+1}:\quad |x\rangle_k|y\rangle*{k+1}\leftrightarrow |y\rangle_k|x\rangle_{k+1}
]

**主循环不变式：**
在处理第 (n) 个 bin 之前，链形态为
[
(A_1,B_1,\dots,A_{n-1},B_{n-1},; S,; A_n,B_n,A_{n+1},B_{n+1},\dots)
]
即 (S) 正好位于待处理的 (A_n) 左侧。

## 5. 逐行流水表：每个 bin (n) 的严格执行顺序

下面给的是**单条轨迹**的一次尝试执行顺序（你做统计就是重复很多条轨迹并平均）。如果你不用轨迹、而用密度矩阵 MPO，则把每个 Kraus 抽样改为对 MPO 施加超算子即可；流水顺序相同。

### 5.1 Bin-n 内核：步骤清单（严格顺序）

> 记当前链局部为：(\cdots - B_{n-1}- S - A_n - B_n - A_{n+1}\cdots)

#### （0）系统内部自由演化与系统噪声（可选但建议每步都有）

- **作用站点：**(S)
- **类型：**one-site unitary + one-site Kraus（或合并）
- **操作：**
  1. (S) 内部哈密顿量自由演化：(U_S(\Delta t)=e^{-iH_S\Delta t/\hbar})
  2. 原子退相干/自由空间散射：({K^{(S)}_\mu}) 抽样一次

> 这样等价于在整个门宽内对原子连续施加退相干；如果你想把“光纤传播时间 (\tau)”显式计入原子等待，也可以在循环结束后额外施加 (\mathcal{E}_{\rm atom}(\tau))，两者择一即可（不要重复加两次）。

------

#### （1）A 端发射（含偏振映射）

- **作用站点：**((S, A_n))
- **类型：**two-site unitary
- **操作：**
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{emit})}_{A,n},|\Psi\rangle
  ]

------

#### （2）A 臂 QFC

- **作用站点：**(A_n)
- **类型：**one-site unitary
- **操作：**
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{QFC})}_{A,n},|\Psi\rangle
  ]

------

#### （3）A 臂滤波/窄带腔（若启用记忆）

- **作用站点：**((S, A_n))
- **类型：**two-site unitary（或 two-site channel）
- **操作：**
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{filt})}_{A,n},|\Psi\rangle
  ]

------

#### （4）A 臂损耗/噪声（器件插损、光纤衰减、QFC 噪声注入等）

- **作用站点：**(A_n)
- **类型：**one-site Kraus（可串多个通道）
- **操作（示意）：**
  [
  |\Psi\rangle \leftarrow \frac{K^{(A,n)}*{\mu},|\Psi\rangle}{\sqrt{\langle\Psi|K^{\dagger}K|\Psi\rangle}}
  ]
  其中 (K^{(A,n)}*{\mu}) 可能由多段串接：(\mathcal{E}*{\rm ins}\circ\mathcal{E}*{\rm fiber}\circ\mathcal{E}_{\rm noise}\circ\cdots)。

------

#### （5）A 臂偏振演化（Jones 旋转；PMD 先不在此处做）

- **作用站点：**(A_n)
- **类型：**one-site unitary
- **操作：**
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{pol})}_{A},|\Psi\rangle
  ]

------

#### （6）SWAP：把 (S) 移到 (B_n) 左侧

- **作用站点：**((S, A_n))
- **类型：**two-site SWAP
- **操作：**
  [
  |\Psi\rangle \leftarrow \mathcal{S}*{S,A_n},|\Psi\rangle
  ]
  此后局部链变为：(\cdots- B*{n-1}-A_n- S- B_n-\cdots)

------

#### （7）B 端发射

- **作用站点：**((S, B_n))
- **类型：**two-site unitary
- **操作：**
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{emit})}_{B,n},|\Psi\rangle
  ]

------

#### （8）B 臂 QFC

- **作用站点：**(B_n)
- **类型：**one-site unitary
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{QFC})}_{B,n},|\Psi\rangle
  ]

------

#### （9）B 臂滤波/记忆（若启用）

- **作用站点：**((S, B_n))
- **类型：**two-site unitary
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{filt})}_{B,n},|\Psi\rangle
  ]

------

#### （10）B 臂损耗/噪声

- **作用站点：**(B_n)
- **类型：**one-site Kraus
  [
  |\Psi\rangle \leftarrow \frac{K^{(B,n)}_{\nu}|\Psi\rangle}{\sqrt{\langle\Psi|K^{\dagger}K|\Psi\rangle}}
  ]

------

#### （11）B 臂偏振演化（Jones）

- **作用站点：**(B_n)
- **类型：**one-site unitary
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{pol})}_{B},|\Psi\rangle
  ]

------

#### （12）SWAP：把 (S) 移到下一对 bin 的左侧，并让 (A_n,B_n) 成为最左侧“可测对”

- **作用站点：**((S, B_n))
- **类型：**two-site SWAP
  [
  |\Psi\rangle \leftarrow \mathcal{S}*{S,B_n},|\Psi\rangle
  ]
  此后局部链形态为：(\cdots -A_n- B_n- S- A*{n+1}-\cdots)

------

#### （13）（可选）PMD 子程序：对“尚未测量的 bins”执行一次 PMD 移位网络

- **作用站点：**({A_k}) 或 ({B_k}) 的邻近 pairs
- **类型：**one-site rotations + 多个 two-site 门（SWAP 链）
- **备注：**见 §6 的 PMD 流水子程序。
- **位置选择：**
  - 若 PMD 只影响“到中站之前”的 telecom 模式，你可以在“(11) 之后、(12) 之前”就对 (B_n) 以及未来 bins 做；
  - 更容易实现的版本是：每个 (n) 处理完后，对剩余未测部分做一次统一的 PMD sweep。

------

#### （14）中站 50/50 BS 干涉（对 (A_n,B_n)）

- **作用站点：**((A_n,B_n))
- **类型：**two-site unitary
  [
  |\Psi\rangle \leftarrow U^{(\mathrm{BS})}_n,|\Psi\rangle
  ]

> 注意：执行完 (U^{(\mathrm{BS})}_n) 后，你就可以把“站点 (A_n) 与 (B_n) 的 telecom 模式”解释为中站输出端口模式（因为测量是在输出端口上进行的，应用 BS 单位ary 后直接在数态基测量即可）。

------

#### （15）探测：对 (A_n,B_n) 的输出模式施加点击/不点击 Kraus，记录 (\mathbf{r}_n)

- **作用站点：**((A_n,B_n))
- **类型：**two-site measurement Kraus（通常可写成四个输出模式对角算符的张量积）
- **操作：**
  1. 计算各点击模式概率：
     [
     p(\mathbf{r}*n)=\langle\Psi|E*{\mathbf{r}_n}|\Psi\rangle
     ]
  2. 抽样得到 (\mathbf{r}*n) 并更新态：
     [
     |\Psi\rangle \leftarrow \frac{M*{\mathbf{r}_n}|\Psi\rangle}{\sqrt{p(\mathbf{r}_n)}}
     ]
  3. 将 (\mathbf{r}*n) 追加到轨迹记录 (\mathbf{r}*{1:n})

------

#### （16）“丢弃/压缩已测 bins”：把 (A_n,B_n) 从张量网络里删除（推荐）

- **物理含义：**这两个站点已被测量投影（轨迹法下已是经典信息 + 已知后测态），不再与系统纠缠。
- **数值目的：**保持 MPS 长度与纠缠增长可控。
- **实现方式（两种等价想法）：**
  - 若测量 Kraus 使其严格变成产品态（常见是 vacuum 或某个定态），则它与其余链几乎无纠缠，可直接截断为 bond dimension 1 并“pop 左端站点”。
  - 或者保留但不再对其做任何门，让 SVD 截断自动把它们与其余部分剥离（效率较低，不建议长期如此）。

------

### 5.2 外层循环：一次尝试（单轨迹）的完整结构

[
\boxed{
\text{Initialize }|\Psi_0\rangle
;\rightarrow;
\text{for }n=1\ldots N:\ \text{执行 §5.1 的 0–16 步}
;\rightarrow;
\text{用 }\mathbf{r}_{1:N}\text{ 判定是否 }\in\mathcal{S}
}
]

- 若 (\mathbf{r}_{1:N}\in\mathcal{S})：输出该轨迹的原子态（对 (S) 中非原子自由度偏迹或投影），计入成功样本。
- 若不在：丢弃。

------

## 6. PMD 子程序：写成“可直接插入主循环”的门序列

假设你对每条臂 (j) 都有 PMD 参数 (\Delta\tau_j)，对应整数移位 (m_j=\mathrm{round}(\Delta\tau_j/\Delta t))。

对某条臂（比如 A 臂）的未测 bins 区间 (k\in[k_{\min},k_{\max}])（通常是当前 (n) 之后的 bins），执行：

### PMD(A, (m_A), (k_{\min},k_{\max}))

1. **PSP 基变换（one-site）**
   对所有 (k\in[k_{\min},k_{\max}])：
   [
   A_k:\quad (c^H,c^V)\mapsto R_{\rm in}(c^H,c^V)
   ]
2. **移位（two-site SWAP 链）**
   如果 (m_A>0)：把 (\mathrm{PSP}_2) 分量向“更早的 bin”移动 (m_A) 格。实现为最近邻门序列（示意）：

对每个 (k) 从 (k_{\min}) 到 (k_{\max}-1)，施加一个只对 (\mathrm{PSP}*2) 子空间起作用的“部分 SWAP”门 (\widetilde{\mathcal{S}}^{(\mathrm{ps2})}*{A_k,A_{k+1}})。
连续扫 (m_A) 次即可实现净移位 (m_A)。

> 你可以把 (\widetilde{\mathcal{S}}^{(\mathrm{ps2})}) 理解为：在每个站点的局域基里，挑出“(\mathrm{PSP}_2) 单光子（以及相关两光子）子空间”，在该子空间做 SWAP，其它（vac、(\mathrm{PSP}_1) 等）保持不动。
> 若你采用的是完整 Fock 截断，这个门就是一个稀疏置换矩阵（实现上很干净）。

1. **逆变换（one-site）**
   对所有 (k\in[k_{\min},k_{\max}])：
   [
   A_k:\quad \mathrm{PSP}\mapsto R_{\rm out}^{-1}(\mathrm{PSP})
   ]

B 臂同理。

## 7. 一句话总结：你最终要“照表施工”的程序骨架

把上面的流水表压成最短的“执行核”语言就是：

- **链初始化：**(S-A_1-B_1-\cdots-A_N-B_N) 全真空 + 原子初态
- **循环 bin：**
  - 在 ((S,A_n)) 做：发射 →（可选滤波）
  - 在 (A_n) 做：QFC → 损耗/噪声 → 偏振 Jones
  - SWAP (S\leftrightarrow A_n)
  - 在 ((S,B_n)) 做：发射 →（可选滤波）
  - 在 (B_n) 做：QFC → 损耗/噪声 → 偏振 Jones
  - SWAP (S\leftrightarrow B_n)
    -（可选）PMD sweep
  - 在 ((A_n,B_n)) 做：BS 干涉 → 探测 Kraus → 记录点击 → 丢弃该 bin
- **门宽结束：**(\mathbf{r}*{1:N}\in\mathcal{S}) 则抽取原子态并统计 (F,p*{\rm succ})。

## 8. 你实现时最容易踩坑的三个“完整性检查”

1. **BSM 截断闭合性检查（必须做）**
   对任意输入态 (|1\rangle_{A_n}|1\rangle_{B_n})（含偏振），施加 (U^{\mathrm{BS}}) 后，检查输出态是否仍在你定义的局域 Hilbert 空间里。若不闭合，说明你把两光子 sector 截掉了，HOM/BSM 会错。
2. **偏振链一致性检查（强烈建议）**
   把“源端偏振映射 (\Alpha^{(\mathrm{emit})})”与“光纤/器件 Jones 链 (U_A,U_B)”组合，先在没有噪声/损耗的极限下跑一个小例子：

- 若 (U_A=U_B) 且 (\Alpha^{(\mathrm{emit})}) 两列正交，应当能恢复接近理想的条件 Bell 态；
- 若 (U_A\neq U_B) 且不补偿，应当看到 (F) 随相对旋转退化。

1. **“双击成功但低保真”的诊断分解**
   当你出现 (p_{\rm succ}) 不低但 (F) 低时，优先区分三类原因：

- 源端 (\Alpha^{(\mathrm{emit})}) 非正交（源头就没纠缠）
- PMD/频率依赖偏振导致不可区分性下降（HOM 可见度下降）
- 噪声/暗计数导致假阳性符合（提高成功率、拉低保真）

这三类在流水表里分别对应不同模块位置，便于你做消融实验（disable 某模块看变化）。
