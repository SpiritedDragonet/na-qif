1.计算出真实的双光子都到达探测器的概率，

A:你这三步的拆分是合理的，而且我建议你把它们用“无条件概率 / 条件概率 / 条件态”三套对象明确写出来，否则很容易在代码里不小心做了“隐含后选（post‑selection）”，导致第 1 步和第 2 步的数值完全失真。

另外先提醒一句：如果你后面还要我去检索你更早上传的一些文件，系统有时会提示部分文件过期需要你重新上传；但你这次上传的这些 Python 代码（`mps.py / channels.py / operators.py / gates.py / trajectory.py` 等）我这里是能直接看到的，不影响我们把指标定义清楚并对着你现有实现来落地。

下面把三件事分别严格定义，并说明在你的 time‑bin MPS/trajectory 框架里怎么计算。

一、定义一次“试验”的数学对象（建议你统一记号）
设一次试验从初态
[
\rho_0 = |e\rangle\langle e|_A \otimes |e\rangle\langle e|*B \otimes |\mathrm{vac}\rangle\langle \mathrm{vac}|*{\text{all bins}}
]
开始。

你做完“发射（原子–bins）+ QFC + 780 滤除/损耗 + 光纤损耗/偏振漂移/相位漂移 + BS”等所有**到达探测器前**的操作后，得到一个“探测前的光场 + 两原子”的态（一般是混态；你若用 trajectory 就是很多条纯态分支的统计）：
[
\rho_{\rm pre} .
]

然后探测阶段对应一个测量 POVM / Kraus 集合 ({M_r})，每个 (r) 是一次试验的“完整观测记录”（例如：哪个 bin 发生了哪种 4 探测器点击模式）。

你最终关心的所有概率和保真度，都可以从
[
p(r)=\mathrm{Tr}(M_r,\rho_{\rm pre},M_r^\dagger),
\qquad
\rho_{AB}(r)=\frac{\mathrm{Tr}*{\rm phot}(M_r,\rho*{\rm pre},M_r^\dagger)}{p(r)}
]
这两个对象推出。

二、你要算的第 1 件事：双光子“真实到达探测器”的概率
你说的“真实到达探测器”，我建议你明确成：

“在进入探测器 POVM 之前，**探测器所对应的光学模式里总光子数等于 2**。”

令探测器所覆盖的所有模式（所有 bin、两输出端口、H/V 两偏振）的总光子数算符为
[
\hat N=\sum_{\text{all det modes }j}\hat n_j.
]
则
[
P_{\rm arrive}(2)\equiv \Pr(N=2)=\mathrm{Tr}\big(\Pi_{N=2},\rho_{\rm pre}\big).
]

在你的截断（最多 2 光子）里，这个定义是完全可实现的。

怎么在你的框架里算？

A) 用 trajectory（推荐，最直观）
你在 `channels.py` 里已经把光纤损耗做成 Kraus 信道了（例如 `loss_channel_1517` / `loss_channel_both_subspaces`）。这意味着：你每条轨迹跑完“损耗前的所有幺正门 + 损耗 Kraus 采样”后，该条轨迹最终会落在一个确定的光子数扇区（0/1/2），不会再是“既有 2 又有 1 的相干叠加”（损耗的 Kraus 结果把环境记录进来了）。

于是你可以在每条轨迹里，在探测前计算一次
[
N_{\rm traj}=\langle\psi_{\rm pre}|\hat N|\psi_{\rm pre}\rangle
]
它会非常接近 0、1、2 中的一个。用阈值判别（例如 (N_{\rm traj}>1.5) 视作 2 光子）即可。统计很多次轨迹：
[
P_{\rm arrive}(2)\approx \frac{#{\text{traj}:N_{\rm traj}\approx2}}{N_{\rm trials}}.
]

这里 (\hat n) 的局域形式你已经固定了：对 6D（1517）基 ((\mathrm{vac},H,V,2H,2V,HV))，单站点总光子数就是对角矩阵
[
\hat n_{\rm site}=\mathrm{diag}(0,1,1,2,2,2).
]
（如果还在 18D bin 空间里，就做 (I_{780}\otimes \hat n_{1517})。）

B) 用解析（不采样），就会涉及 MPO 或全链投影（不建议你现在优先走）
因为平均损耗会把态变混态，你要么上 MPO/密度矩阵表示，要么做生成函数提取系数；对你当前进度不划算。

非常重要的实现提醒（这会直接影响第 1 步是否“真实”）
你现在 `trajectory.py` 的 `apply_780_filter()` 是用投影 (P_{\rm filter}=|vac\rangle\langle vac|*{780}\otimes I*{1517}) 然后最后 `renormalize=True` 归一化。这个做法本质是在“后选：只保留 780 子空间本来就是 vac 的分支”，等价于把“QFC 未转换成功”的那部分概率直接丢掉了。这样你算出来的 (P_{\rm arrive}(2)) 会被严重高估。

如果你要做第 1 步“真实概率”，780 滤除应该用一个**迹保持**的损耗信道（你 `channels.py` 里其实已经写好了）：把 `eta_780=0` 交给 `loss_channel_both_subspaces`，并用 Kraus 采样来实现，而不是单个投影算符再归一化。

三、你要算的第 2 件事：在“双光子都到达”的子集里，判定纠缠成功的概率
这一步建议你定义成条件概率：

设你定义的“成功判定”事件为 (S)（例如：在某个 bin 内出现某种两探测器 coincidence，并且其它 bin 没有额外点击；或者允许 jitter 窗跨 bin 合并等）。则
[
P_{\rm succ|arrive2}=\Pr(S,|,N=2)=\frac{\Pr(S\cap {N=2})}{\Pr(N=2)}.
]

在 trajectory 里非常好算：

- 对每条轨迹，你已经会生成一个“探测记录” (r)（所有 bin 的 4 比特点击模式序列）。
- 你同时也能得到该轨迹在探测前的 (N_{\rm traj}\approx0,1,2)。

于是统计：
[
P_{\rm succ|arrive2}\approx
\frac{#{\text{traj}: N_{\rm traj}\approx2 \ \text{且记录 }r\in S}}
{#{\text{traj}: N_{\rm traj}\approx2}}.
]

成功事件 (S) 怎么选？
你可以先不要信任何“注释里写的 Psi± 对应哪个模式”，而是用一个更稳的方法来避免符号/相位约定错误：

做一个“事件‑到‑原子态”的字典：
对每一种你可能接受的两点击模式（例如同一 bin 的 H1&V2、V1&H2、H1&V1、H2&V2 等），直接在仿真里算出该模式条件下的 (\rho_{AB}(r))，看它和四个 Bell 态的保真度谁最高，然后把它归类为“这条模式 herald 哪个 Bell 态”。这样你的 (S) 集合是数据驱动的，不会被 BS 相位约定带偏。

一个 sanity check（理想极限下你应该看到的数）
若：两光子完全不可区分、BS 真正 50/50、无损耗、无暗计数、无抖动，并且你把“产生两点击的 HV coincidence”都算成功（既包括跨端口 HV，也包括同端口 HV），那么在 (N=2) 的子集里，理论上 (P_{\rm succ|arrive2}) 会是 1/2 量级（因为输入的 HH/VV 那一半会 bunch 成 2H/2V，桶式探测不会给你两点击）。如果你只接受跨端口 HV coincidence，则会进一步降到 1/4 量级。这是你对代码的一个很强的自洽性检验。

四、你要算的第 3 件事：在“被判定为成功”的样例下，纠缠 Bell 态的保真度
你要的就是一个条件态质量指标。推荐你用“成功条件下的原子态混合”来算（而不是先算每条轨迹的 fidelity 再平均；两者等价但前者更清晰）。

# 定义成功条件下的原子态（对所有成功记录求和得到的后验混态）： [ \rho_{AB}^{\rm succ}

\frac{1}{P_{\rm succ}}
\sum_{r\in S}
\mathrm{Tr}*{\rm phot}\big(M_r,\rho*{\rm pre},M_r^\dagger\big),
\qquad
P_{\rm succ}=\sum_{r\in S}p(r).
]

然后你要比较的目标 Bell 态 (|\Psi_{\rm target}\rangle)（例如 (|\Psi^-\rangle=(|01\rangle-|10\rangle)/\sqrt2)），保真度定义为
[
F=\langle\Psi_{\rm target}|\rho_{AB}^{\rm succ}|\Psi_{\rm target}\rangle.
]

两条关键实践注意事项：

1. 先投影到原子量子比特子空间再算 fidelity
   你的原子是 3 维（(|0\rangle,|1\rangle,|e\rangle)）。探测成功后理论上 (|e\rangle) 应该几乎没有，但数值上可能残留。通常做法是先投影到 qubit 子空间 (P=(|0\rangle\langle0|+|1\rangle\langle1|)^{\otimes2})，再归一化：
   [
   \rho^{\rm qubit}*{AB}=\frac{P,\rho^{\rm succ}*{AB},P}{\mathrm{Tr}(P,\rho^{\rm succ}*{AB})}.
   ]
   最后用 (\rho^{\rm qubit}*{AB}) 去算 Bell fidelity。
2. 一定要做“按探测结果的 Pauli 纠正/Pauli frame”，否则你会把好态平均没了
   不同点击模式通常 herald 不同的 Bell 态（例如 (\Psi^+) vs (\Psi^-)），它们是正交的。你如果把两类都算“成功”但不做纠正，最后 (\rho^{\rm succ}_{AB}) 会变成它们的混合，fidelity 可能直接掉到 1/2 左右，看起来像“纠缠质量差”，其实只是你把两种 Bell 态混在一起了。

# 做法是：对每个成功记录 (r)，先对原子态施加一个依赖于 (r) 的局域酉 (U_{\rm corr}(r))（对应一次 X/Z 纠正或等价的 Pauli frame 更新），把它们都映射到同一个目标 Bell 态再相加： [ \rho_{AB}^{\rm succ,corr}

\frac{1}{P_{\rm succ}}
\sum_{r\in S}
U_{\rm corr}(r),
\mathrm{Tr}*{\rm phot}(M_r\rho*{\rm pre}M_r^\dagger),
U_{\rm corr}^\dagger(r).
]
然后再算 (F=\langle\Psi_{\rm target}|\rho_{AB}^{\rm succ,corr}|\Psi_{\rm target}\rangle)。

五、把三步连成一条“可报告的指标链”
你最终最好同时报告下面三个数（它们互相之间能自洽校验）：

1. 双光子到达概率：(P_{\rm arrive}(2))
2. 条件成功率：(P_{\rm succ|arrive2})
3. 成功条件下保真度：(F)

并且给出无条件 herald 概率（真实实验里能直接对应到“每次尝试成功多少次”）：
[
P_{\rm succ}=P_{\rm arrive}(2)\times P_{\rm succ|arrive2}
]
（若你把暗计数也算进成功判定，则上式严格来说还会有“无光子但暗计数误触发”的补充项；用 trajectory 计数时会自动包含。）
