## 六、你问的“矩阵幅度要多小才能释放到某个 bin 里”——在你当前门模型下的精确关系

你现在的发射门是
[
U_n=\exp(\sqrt{\Delta t}(L\otimes b_n^\dagger - L^\dagger\otimes b_n)).
]
这类门在“单激发 + bin 初态真空”时有一个非常实用的精确结论：每一步的“发射概率”并不等于你塞进去的 (\gamma(t))，它还要乘以“此时还没发射的生存振幅”。

你自己在笔记里也已经点到了这一点：一般是 (|w(t)|^2=\gamma(t),|c_{\rm exc}(t)|^2)，而不是 (|w(t)|^2=\gamma(t))。

把它写成更可操作的形式：

- 若用连续时间的有效波导模型（原子直接耦合外场），在无其他哈密顿量时
  [
  \dot c_e(t)= -\frac{\Gamma(t)}{2}c_e(t),\qquad
  w(t)=\sqrt{\Gamma(t)},c_e(t),
  ]
  因而
  [
  |w(t)|^2 = \Gamma(t)\exp!\Big(-\int^t \Gamma(t')dt'\Big).
  ]
  所以你“手写一个高斯 (\Gamma(t))”通常不会得到高斯波包强度，这就是你觉得“不够物理”的根源之一。

- 若用离散 bin，并且你想反过来“指定目标波包 (q_n)”来求每步应该发射多少（这在你现在的 sequential‑MPS 结构里是非常直接的），你笔记里给了离散反求公式：
  [
  \xi_n=\sqrt{\epsilon_n}\prod_{j<n}\sqrt{1-\epsilon_j}e^{i\phi_n},\qquad
  \epsilon_n=\frac{q_n}{1-\sum_{j<n}q_j}.
  ]

  而在你用的这类“碰撞幺正”里，(\epsilon_n) 与门强度大致满足 (\epsilon_n\simeq \sin^2(\theta_n))，其中 (\theta_n\sim \sqrt{\Gamma_n\Delta t})（小步长时 (\epsilon_n\approx \Gamma_n\Delta t)）。于是你可以把“每步门的矩阵幅度”定量地解出来：
  [
  \Gamma_n = \frac{\arcsin^2(\sqrt{\epsilon_n})}{\Delta t}\quad(\text{精确到该二能级子块的理想化模型}).
  ]
  这就把“每个 bin 该释放多少概率”与“你门里要用多大的 (\gamma)”精确连起来了。

注意：这套反求只是在数学上让你的离散门生成某个目标波包；它仍然不是“从 (\Omega(t),g,\kappa) 正推”——它是“从目标波包反推门强度”。如果你要实验指导意义，最终还是应该让 (\Omega(t)) 和腔参数决定波包，而不是你决定 (\gamma_n)。
