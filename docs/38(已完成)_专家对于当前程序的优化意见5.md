## A. 我认为你现在“真的有问题”的地方（会直接导致指标算错/自相矛盾）

### A1) `compute_metrics()` 里 **diff-bin 两次点击的计数少了一半**（时间顺序漏算）

你在 `run_detection_pipeline()` 抽样记录时，对每个 detector pair 都把**两种时间顺序**都加进来了：

- `... _collect_diff_bin_records(det_a, det_b, ...)`
- `... _collect_diff_bin_records(det_b, det_a, ...)`

这样才能覆盖“先点 A 后点 B”和“先点 B 后点 A”。

但是 `compute_metric:contentReference[oaicite:8]{index=8}bins`）时，只算了一个方向（`key_a` 在较早 bin、`key_b` 在较晚 bin），并没有把反向也加上。你现在的 `patterns_success` 里 detector 的排列不是“按时间”，而是“按端口/书写习惯”，因此这会**系统性漏掉**另一半的 diff-bin 成功事件。

**后果**

- `p_succ:contentReference[oaicite:10]{index=10}rue` 会被低估（当 diff-bin 贡献不小的时候，误差接近 2 倍）。
- 加权保真度分子也会被低估；最终 `fidelity_declared_*` 可能还“碰巧差不多”，但那是因为分子分母一起漏，不能信。
- 更糟的是：你的抽样（records sampling）和枚举（compute_metrics）会互相对不上，调参时会非常迷惑。

**怎么改（最小改动）**
对所有你在 `compute_metrics()` 里用 `_sum_diff_bins(effects_by_bin, key_a, key_b, ...)` 的地方，都应该把反向再加一次：

- `w += _sum_diff_bins(..., key_a, key_b, ...)`
- `w += _sum_diff_bins(..., key_b, key_a, ...)`

同理，对 fidelity 分子那一套也要对称加（否则你修了成功概率但 fidelity 又不一致）。这属于“必须修”的一致性 bug。

### A2) `Psi+n 算成功，但枚举只算 same-bin（逻辑不一致）**

你在抽样阶段把 `("H1","V1")`、`("H2","V2")` 这种 `Psi+` 模式也放进了 diff-bin records（同样做了两种顺序）。然后判 success 用的是

- 且 `abs(bin_a-bin_b) <= window_bins`

也就是说：只要在窗口内、哪怕两个点击发生在不同 bin，你也会把它当作 “Psi+ 成功”。

但 `compute_metrics:contentReference[oaicite:14]{index=14}m_same_bin(effects, ("H1","V1"))` / `("H2","V2")`，完全没把 diff-bin 的 `("H1",) @ ("V1",)` 这类加入。

**这不是“偏好不同”而是“代码自相si+`？

- 如果你认为 `Psi+` 必须是**同一时间 bin 的双点击**（更接近“同一时刻两光子 bunching”那种物理图像），那你就应该让抽样阶段对 `Psi+` 强制 `bin_a == bin_b`。

这条同样属于“必须统一”的一致性问题。

## B. 物理模型层面：“看起来很精致但指导不了实验”）

### B1) 你用的“坏腔近似/消去腔模”公式：**系数和适用区间要确认**

你现在用的是：

```python
gamma = 2*kappa_ex*(g/kappa)**2
# kappa = kappa_ex + kappa_in
```

并且注释里写 `L_eff ≈ sqrt(2*kappa_ex) * g / kappa`。

这在“输入输出方程写法/κ 的定义”4 倍（常见写法里场幅衰减是 κ/2，而 master 方程里是 κ D[a]）。标准输入输出形式下，腔模绝热消去常见会得到类似 `Γ ~ 4 g^2/ comport` 的量级（并带上外耦合比例 κ_ex/κ）。([arXiv](https://arxiv.org/html/2407.04784v1))

你现在的 `2*kappa_ex*(g/kappa)^2` 在 κ_ex≈κ 时给 `2 g^2/κ`，而不少文献写法会出现 `4 g^2/κ` 级别。是不是“差一半”取决于你 κ 的定义（幅衰减还是能量衰减）以及你在消去里是不是漏了一个 2。这个点不确认，你后面所有波包、亮度、多光子概率都会跟实验不在一个标尺上。

**我建议的做法（对实验指导最关键）**

1. 明确你代码里 g、κ_ex、κ_in 的单位和定义到底是哪一种（幅衰减 or 能量衰减）。
2. 用一个“可对照的可观测量”来定标：比如单原子在无驱动时的 e 态寿命（Purcell 增强后）、或者输出光子数 vs 时间的指数尾巴。把模拟结果和你腔参数给出的解析预期/实验测量对齐。
3. 如果你实际系统是“高 finesse + 不是很坏的腔”（κ 并不最大），那**仅用有效 gamma 的 Markov 发射门**会丢掉腔的记忆效应与波包形状细节，这会直接影响 HOM 干涉和 BSM 保真度；这种情况下更合理的是把腔模当成显式自由度（每个偏振一个腔模）再耦合到 time bins（time-bin MPS 方法完全支持这种扩展，只是局域维数更大）。([APS Links](https://link.aps.org/doi/10.1103/PhysRevLett.115.060402))

### B2) 你把“可见度 visibility”当成独立旋钮：对实验是有用的，但要避免“双重计入”

你在 `build_detection_effects_6d()` 里构造了一个很聪明的“区分光子/不可区分光子”混合模型：用 9D 带标签的空间做 `E_dist`，然后 `E = visibility*E_int + (1-visibility)*E_dist`。

这在做 HOM 可见度退化时是个常见的有效模型：可见度本质上刻画两光子在所有自由度上的重叠，很多结果对 overlap 是线性的。([Wikipedia](https://en.wikipedia.org/wiki/Hong–Ou–Mandel_effect))

但你同时又显式加入了：

- 两臂的随机 Jones 旋转（偏振漂移）
- PDL（η_H ≠ η_V）
- 相位漂移 / phase slope / bin-to-bin 随机相位

这些本身也会降低“有效 HOM 可见度/有效 Bell 投影质量”。如果你把 visibility 又设得很小，你可能会把同一类可区分性“算两遍”。

**建议**

- 把 visibility 定义为：在你已经加入偏振漂移/相位噪声之后，剩余的“不可建模/你不想细分的”模不匹配（时域、频域、空间、频谱滤波造成的形状差异等）。
- 更进一步：如果你愿意让模型更“对实验有指导意义”，可以尝试把 visibility 从“旋钮”改成“由模拟波包直接算 overlap”：例如从你 time-bin 的两光子态（或等效的单光子模式密度矩阵）计算模式重叠，再映射到 HOM dip。这样你能把 delay jitter、频率差、波包形状差真正串到一起，而不是分散成多个独立噪声参数。([Wikipedia](https://en.wikipedia.org/wiki/Hong–Ou–Mandel_effect))

### B3) QFC 你现在等价成 “幺正旋转 + 780 filter + 背景暗计数”：**大方向对，但噪声结构可能太粗**

你用 `qfc_gate(theta_H, theta_V)` 做频率转换（等效 beam-splitter 旋转），再用 `apply_filter_780` 把未转换的 780 完全抹掉，噪声主要通过 `dark_rate_bg_hz` 并入 Poisson dark counts。

实验上，780→电信波段的 QFC 往往最麻烦的不是“效率”，而是**泵浦诱导的噪声光子**（Raman、SPDC/差频过程产生的背景），并且它可能：

- 不是完全均匀的（跟泵浦时序相关）
- 偏振/频谱可能不等（滤波带宽决定）
- 在某些实现里甚至出现相关噪声（非完全独立 Poisson）

你现在用一个均匀 dark rate 去吸导trade-off 亮度与噪声），可能不够细。相关实验和讨论里经常强调“低噪声转换”和滤波策略的重要性。([Advanced Online Library](https://advanced.onlinelibrary.wiley.com/doi/10.1002/qute.202300228))

**建议的最小升级（仍然不破坏你现有结构）**
把 QFC 噪声从“探测端 dark count”升级为“光场端的背景光子注入”，至少做到：

- 背景光子以某个谱/偏振分布注入到 bin 中（可先做：以概率 p_bg 给每个 bin 在 H/V_1517 中随机塞一个单光子，等效热噪声近似），然后再走 BS 和探测。
  这样噪声就会和 BS 干涉/端口相关，能更真实反映“噪声光子也会产生某些‘像成功’的点击模式”。([Advanced Online Library](https://advanced.onlinelibrary.wiley.com/doi/10.1002/qute.202300228))

### B4) 光纤你现在是 “随机 SU(2) + PDL + 相位噪声”：缺的主要是 **PMD/色散导致的时间模式混合**

你用 Jones 矩阵给偏振旋转，用 η_H/η_V 给 PDL，然后加 global phase + phase slope + bin-to-bin 相位抖动。

这些对“偏振不对齐 + 相干相位漂移”很有效。但 16 km 量级的光纤，如果你做 HOM/BSM，实验上经常还得关心：

- **PMD（polarization mode dispersion）**：等效为 H/V（更准确是主态）之间的微小群时延差，会把偏振自由度和时间自由度纠缠起来，降低可干涉性。([Optica Publishing Group](https://opg.optica.org/opticaq/fulltext.cfm?id=567514&uri=opticaq-3-1-55))
- **色散/滤波造成的波包展宽**：会影响到你“一个 bin 表示一个正交时间模”的假设精度，从而影响 coincidence window 的最优选择。

你现在的模型完b被你通过“visibility 旋钮”或“delay/jitter”去拟合，而不能用来指导“光纤补偿/滤波/时间窗”的具体设计。

**建议（按投入从小到大）**

- 小投入：加一个“偏振相关的到达时间抖动/延迟”，即对某一臂（或某一偏振分量）引入一个把振幅从 bin n 泄漏到 bin n±1 的卷积核（离散 FIR）。这会把 PMD/色散变成一个可控参数（展宽、群时延差）。
- 更真实：把光纤当成一个频率相关的 Jones（需要频域表示）——这会复杂很多，不建议你一上来就做，但你可以先用 “PMD 等效两条主态延迟差” 的模型。([Optica Publishing Group](https://opg.optica.org/opticaq/fulltext.cfm?id=567514&uri=opticaq-3-1-55))

## D. 你现在还缺哪些“该仿但没仿”的因素？哪些简化可能“过度到失去指导意义”？

我按“对 fidelity/ Bell 投影退化最敏感”的顺序排：

### D1) 两端原子/腔参数不一致（频率/耦合/波包）——这是导致可见度掉下来的常见主因

你目前的 `delta_u, delta_e, g, kappa_ex, kappa_in` 是对两臂共用的ns`和`Omega_peak` 区分。

实验里常见的是：

- 两个腔的共振频率略不同
- 两个原子/量子点的跃迁频率漂移不同（spectral diffusion）
- 两边耦合 g 不同（对准/振动/原子位置）

这些会直接改变单光子的频谱与时域波包，从而降低 HOM 干涉可见度，影响 BSM fidelity。你当然可以把它们粗略折到 visibility 里，但那就失去“指导意义”：你没法告诉实验该调哪一颗腔、需要多强的锁频。

**建议**
在 emission 模块层面增加 “A/B 独立的 detuning 与 coupling”：

- `delta_e_A, delta_e_B`（或等效频率差 Δω），对应你 detection 端的 `phase_slope` 可以做“由频差推出来”而不是另采样一个旋钮。([Wikipedia](https://en.wikipedia.org/wiki/Hong–Ou–Mandel_effect))
- `g_A, g_B`, `kappa_*_A/B`：直接决定波包形状与亮度（这比单）。

------

### D2) 自由空间自发辐射/非腔输出通道（有限 cooperativity 的“致命误差源”）

你目前的发射通道只有两条（H/V）并且都进入 time-bin 光场，等效假设“所有辐射都进了你可收集的腔外耦合端口”。

高 finesse 并不等价于无限 cooperativity；现实里 excited state 还会有：

- 自由空间散射（导致“发了但你没收集到”，并且可能把原子打到错误态/带来去相干）
- 腔内损耗端口（κ_in）对应的不可收集辐射

你目前把 κ_in 只放在 `kappa = kappa_ex + kappa_in` 里影响 gamma，但没有显式地把“进 κ_in 端口的光子”当作环境自由度（或者等效 loss）。这会影响：

- heralding rate（你倒是可能通过 eta_mean 之类吸收掉）
- 更关键：原子态是否被投影到正确的 qubit 子空间（散射导致的错误态/去相干）

如果你目标是“指导实验”，建议至少加一个等效 Lindblad：

- `L_loss ~ sqrt(gamma_loss) * (|0><e|, |1><e|)` 但把光子丢到不可见环境（等效为发射后原子态变混）。

------

### D3) 探测器时间抖动/门宽与 binning 的对应

你现在把 n分辨/门宽（决定 p_dark per bin 与 coincidence window bin 数）

这在“dt 同时满足数值离散和实验电子学分辨”时 OK，但在真实系统里经常是两套尺度：
你为了数值精度可能要 dt=0.1 ns，但探测器有效门宽可能是 1 ns 或更大；暗计数按门宽算会差一个数量级。

**建议**
把 “数值 dt” 和 “探测时间 bin 宽度” 解耦：

- emission 用细 dt
- detection 用更粗的 time bin（或把 fine bins 合并成 coarse bins，并正确合并 POVM/暗计数）

这会显著影响你“窗口内 diff-bin 事件”的权重，从而影响 fidelity 退化曲线。
