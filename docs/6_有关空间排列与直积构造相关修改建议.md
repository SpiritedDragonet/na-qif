Q：那波包形状这块是怎么体现出来的？
A：在 time-bin/MPS 的建模里，“波包形状”不是额外加进去的一条曲线，而是直接体现在“光子落在不同 time-bin 上的概率振幅分布”上。

你可以把每个 bin 理解成一个时间片 $[t_n, t_n+\Delta t$) 对应的时域模式：
$$
b_n \equiv \frac{1}{\sqrt{\Delta t}}\int_{t_n}^{t_n+\Delta t} b(t),dt,
\qquad [b_n,b_m^\dagger]=\delta_{nm}.
$$
于是单光子波包在离散后就是
$$
|\psi_{\rm ph}\rangle=\sum_n\left(\xi_n^{H},|1H_n\rangle+\xi_n^{V},|1V_n\rangle\right),
\quad \sum_n\big(|\xi_n^{H}|^2+|\xi_n^{V}|^2\big)=1.
$$
这里的 ${\xi_n}$（随 (n) 变化）就是波包的离散时间包络；连续包络近似为 $\xi(t_n)\approx \xi_n/\sqrt{\Delta t}$。

一、在你的 Hilbert 截断里，波包“怎么读出来”

你现在每个 bin 的本地空间是 780(3 维) ⊗ 1517(6 维)＝18 维。你关心的通常是 1517 段到中站的波包，所以只要在每个 bin 上定义 telecom 的数算符即可。

1517 的 6 维基（你给的）可对应占据数 $(n_H,n_V)$：

- vac: (0,0)
- 1H: (1,0)
- 1V: (0,1)
- 2H: (2,0)
- 2V: (0,2)
- HV: (1,1)

所以 1517 子空间上的数算符对角就是：

- $N_H^{(1517)}=\mathrm{diag}(0,1,0,2,0,1)$
- $N_V^{(1517)}=\mathrm{diag}(0,0,1,0,2,1)$

对完整 18 维 bin（含 780）：
$$
N_H^{\rm bin}=I_{780}\otimes N_H^{(1517)},\quad
N_V^{\rm bin}=I_{780}\otimes N_V^{(1517)}.
$$
然后在仿真过程中（比如 QFC 后、进入中站 BS 前）对每个 bin (n) 计算
$$
p_n^{H}=\langle N_{H,n}^{\rm bin}\rangle,\quad
p_n^{V}=\langle N_{V,n}^{\rm bin}\rangle,\quad
p_n=p_n^{H}+p_n^{V}.
$$
这条序列 ${p_n}$ 就是强度波包包络；若你只在单光子子空间内工作，$p_n$ 也等价于 $|\xi_n|^2$。

如果你想要“复振幅”（相位信息），就要取 $\xi_n$ 本身而不只是 $p_n$。常见做法是定义投影到 $|1H_n\rangle$、$|1V_n\rangle$ 的振幅（等价于对状态做适当收缩/投影），从而得到 $\xi_n^{H/V}$。这一步对 HOM 可见度/模式重叠很有用。

二、波包形状“从哪儿来”：发射门的时间依赖就是波包整形

在 collision/time-bin 方案中，每个时间步你做一次“原子 ⊗ 当前 780 bin”的局域门 $U_{\rm emit}(n)$。如果这个门的耦合强度随时间变化（即随 bin 变），输出波包就自然被整形。

最直观的等效参数是“有效辐射率” $\gamma(t)$$或 Raman 驱动 $\Omega(t)$$。在连续极限下，常见关系是
$$
\xi(t)\propto \sqrt{\gamma(t)},\exp!\left(-\tfrac12\int_0^{t}\gamma(s),ds\right).
$$
离散到 bin 上就是：第 (n) 个 bin 的发射概率与当前激发态剩余占据 $P_e$ 及 $\gamma_n\Delta t$ 成正比；你改变 $\gamma_n$ 的时间轮廓，就改变 ${p_n}$ 的轮廓。

因此，“波包整形”在代码层就是：每个 bin 用不同参数生成 $U_{\rm emit}(n)$$或生成不同的 $L(t_n)$$，其余流程不变。

三、波包畸变“从哪儿来”：器件记忆/滤波/色散就是跨 bin 的线性变换

你要研究的畸变主要来自两类机制：

1. 具有有限带宽/记忆的器件（窄带滤波腔、某些 QFC + 滤波链）：
   这会把一个原本集中在若干 bin 的波包“拖尾”到后续 bin，表现为 $p_n$ 的长尾、以及 $\xi_n$ 的相位/幅度改变。数值上最稳的实现是把滤波腔模并入系统，然后让它顺序耦合每个 bin——波包畸变会自动出现。
2. 光纤色散/PMD：
   色散本质是频域相位 $\exp[-i\beta_2 L\Omega^2/2]$，时域体现为跨 bin 的卷积/混合；PMD 则会把偏振与到达时间耦合。需要时可以用“短程 FIR 线性网络”或“PSP 基+差分延迟的 SWAP 链”来实现跨 bin 变换。做完后同样用 ${p_n^{H/V}}$ 读出畸变。

四、和“双光子符合/BSM”的关系：波包形状最终进入的是“模式重叠”

在中站 HOM 干涉里，波包是否匹配直接决定可见度，从而决定条件纠缠保真度。用离散波包表示，最常用的量是两臂的模式重叠
$$
\mathcal{M}=\left|\sum_n \big(\xi_{A,n}^{H*}\xi_{B,n}^{H}+\xi_{A,n}^{V*}\xi_{B,n}^{V}\big)\right|^2.
$$
因此你需要的不只是“有没有到达”，而是“到达时的时间-偏振模式是否一致”。这也是为什么波包形状必须在 time-bin 框架里被显式表示出来。

一句话总结：波包形状就在各个 time-bin 的占据概率/振幅里；发射门的时间依赖决定“生成的波包”，滤波/色散/PMD 等跨 bin 变换决定“畸变后的波包”，而中站干涉与双击的成功率/保真度取决于两臂波包的模式重叠。

  - `An`：A 臂第 n 个 time-bin（18D：780(3)×1517(6)）
  - `Bn`：B 臂第 n 个 time-bin（18D）

如果你现在把两原子合成了一个 9D system site，也可以；只是“发射门”会稍微麻烦（要么三站点门，要么用 swap 把目标 bin 拉到 system 旁边）。我下面先写“两原子分开”的版本，逻辑最干净。

------

### 1) 一次 trial 的主循环（time-bin “车厢过门”）

核心思想：每个时间片 (n)，你做一次“源端生成 → 频转/通道 → 中站干涉 → 探测条件化”。探测之后，该时间片的光场已经被测量（变成经典记录），理论上可以丢弃。

伪代码如下$`#` 后面标出门类型$：

```python
# 输入：
# psi: 当前纯态 MPS（量子轨迹的一条样本）
# n_bins = N
# 所有 bins 初始为 vacuum
# rng: 随机数发生器（轨迹抽样）
# success_patterns: 成功的双击模式集合
# 说明：
# - apply_U_2(i,i+1,U): 两站点幺正门（two-site unitary），用 theta+SVD 局部更新
# - apply_U_1(i,U): 一站点幺正门（one-site unitary），建议内部也用“U ⊗ I”的 bond 更新实现
# - apply_K_1(i, {Kμ}): 一站点 Kraus 抽样更新（one-site Kraus），用局部更新，不触发全链 sweep
# - apply_M_2(i,i+1, {Mμ}): 两站点测量 Kraus（measurement Kraus），抽样 outcome

for n in 1..N:

    # (1) 源端发射：原子与本臂 780 模式纠缠并把光子写进 time-bin
    # two-site unitary（原子 site ⊗ bin site）
    U_emit_A = emission_gate_A(n)     # 依赖你的 γ_A(t_n) / Ω_A(t_n) 等
    apply_U_2(A0, An, U_emit_A)       # two-site unitary

    U_emit_B = emission_gate_B(n)
    apply_U_2(B0, Bn, U_emit_B)       # two-site unitary

    # (2) QFC：780→1517（在同一个 bin 的内部自由度上）
    # 你把 780×1517 合成一个 18D site 时，QFC 是 one-site unitary
    U_qfc = qfc_gate()                # 通常不随 n 变（或随泵浦整形变）
    apply_U_1(An, U_qfc)              # one-site unitary
    apply_U_1(Bn, U_qfc)

    # (3) 偏振链路：Jones 旋转 / 光学补偿（one-site unitary）
    U_pol_A = jones_gate_A(n)         # 可固定或随机抽样（漂移）
    apply_U_1(An, U_pol_A)

    U_pol_B = jones_gate_B(n)
    apply_U_1(Bn, U_pol_B)

    # (4) 通道损耗/器件插损/PDL 等：Kraus 抽样（one-site Kraus）
    # 你 1517 子空间是 6D（vac, H, V, 2H, 2V, HV），损耗 Kraus rank 很小（≤6）
    K_loss_A = loss_kraus_set_A(n)    # 返回 {Kμ}（作用在 bin 18D 的 telecom 子空间，其余为 I）
    apply_K_1(An, K_loss_A, rng)      # one-site Kraus（局部更新 + 归一化）

    K_loss_B = loss_kraus_set_B(n)
    apply_K_1(Bn, K_loss_B, rng)

    # (5) 中站干涉：对 An 与 Bn 的 1517 模式做 beamsplitter（two-site unitary）
    U_bs = beamsplitter_gate()
    apply_U_2(An, Bn, U_bs)           # two-site unitary（现在 An/Bn 必须相邻，或你用 swap 先拉近）

    # (6) 探测 POVM：对这对输出模式做“点击/不点击/暗计数”的测量 Kraus（two-site measurement）
    # outcome 是一个点击模式，例如 (D1H, D2V) 或 “no-click”等
    outcome = apply_M_2(An, Bn, measurement_kraus_set(n), rng)

    record(outcome, n)

    if outcome in success_patterns:
        # 成功：此时 psi 已经是条件化后的纯态
        # 取两原子约化态 rho_AB，并计算 Bell fidelity（注意 pattern->目标Bell态或Pauli修正）
        rho_AB = get_rho_segment([A0, B0])
        return SUCCESS, rho_AB, outcome, n

    else:
        # 失败：继续下一时间片（no-click / 单击 / 非目标双击 都算失败）
        # 这时 An,Bn 已经“被测量”，理论上可以丢弃（实现上可冻结/不再访问）
        continue

# 所有时间片都没成功
rho_AB = get_rho_segment([A0, B0])
return FAIL, rho_AB, None, None
```

这就是“车厢过门”的最核心版本：每个 time-bin 是一节车厢，依次经过发射门、QFC 门、偏振门、损耗 Kraus、BS 门、测量 Kraus。测量后这节车厢就变成经典记录（点击与否），不再需要保持在量子态里。

### 2) 波包形状怎么在这段流程里“体现出来”

在这个框架里，波包形状就是 ${p_n}$ 或 ${\xi_n}$：

- 强度包络（最常用）：在进入中站 BS 之前，计算每个 bin 的 telecom 光子数期望
  $$
  p_n = \langle N^{(1517)}*{H,n}+N^{(1517)}*{V,n}\rangle.
  $$
  对每个 (n) 画出 $p_n$ 随 $t_n=n\Delta t$ 的曲线，就是波包强度形状。
- 复振幅（用于 HOM 可见度/模式重叠）：你需要理解为在单光子子空间中
  $$
  |\psi\rangle \sim \sum_n (\xi_{A,n}^H |1H\rangle_{A,n} + \xi_{A,n}^V |1V\rangle_{A,n}) \otimes \cdots
  $$
  你可以通过对状态做投影/收缩提取 $\xi_{n}^{H/V}$$工程上会比算 $p_n$ 稍复杂，但能给你相位信息$。

波包“整形”就在 `emission_gate_A(n)` / `emission_gate_B(n)` 的时间依赖参数里$例如 $\gamma(t_n)$ 或 $\Omega(t_n)$ 的轮廓$；波包“畸变”则来自滤波/PMD/色散等跨 bin 的线性操作（如果你未来要加的话）。

------

### 3) 两个你实现时最容易卡住的现实点

1. **An 与 Bn 必须在做 BS 时相邻**
   如果你的 MPS 排列是 `A0, B0, A1, B1, A2, B2,...`，那么 `An` 与 `Bn` 本身是相邻的（很好）。
   但如果你把 system 合并、或者把 bins 分别放在两条链上，就需要用 swap 网络把对应 time-bin 拉到一起再做 BS。
2. **Kraus/测量绝对不要用 `apply_local_op` 的非幺正路径**
   你的担心完全成立：非幺正 `apply_local_op` 会触发 canonical sweep，链一长就炸。你应该把 `apply_K_1` 与 `apply_M_2` 都写成“局域 theta 更新 + set_svd_theta 写回”，保证每一步只影响局部 bond。
