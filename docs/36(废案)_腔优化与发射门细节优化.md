你现在实际采用的是一个很关键的策略：发射阶段用 MPS+TEBD（碰撞模型）显式生成“原子–时间分辨光场”的纯态；而 QFC、滤波、光纤、BS、探测器效率/暗计数等后续链路，不再在态上做演化，而是推到测量端（Heisenberg picture / adjoint map），把这些过程折叠进每个 time-bin 的 POVM effect 里，然后用 MPO/环境张量做概率与条件原子态的计算。这个策略在数值上非常合理：否则 BS+损耗等会把纠缠结构弄得很“长程”，MPS bond dimension 会爆得更快。你在代码里也明确写了“方案B：不对 MPS 做操作，统一推到测量端 effect”这一点。

二、P0 级问题：不修会让物理/结果解释明显跑偏

1. 发射模型里把 γ(t) 设成 ∝ |Ω(t)|²，同时又显式保留 |u⟩–|e⟩ 的 Hamiltonian 驱动，这在物理上非常可疑

在 run_dual_atom_emission 里，你先算一个“每个极化通道”的 γ_per_channel，然后每个 time bin 又用 norm_factor = |Ω(t)|/|Ω_peak| 去把 γ 乘上 norm_factor²：gamma_A_n = gamma_per_channel*(norm_factor_A**2)。

这意味着：当 Ω(t) 接近 0 时，你的系统–浴耦合 L_H,L_V 也接近 0，于是即使 |e⟩ 上还有残余布居，也不会继续往外辐射（会“冻结”在 |e⟩）。同时你又没有把 gamma_atom（自由空间自发辐射）或 κ_in 对应的“腔内损耗通道”作为额外 Lindblad/jump 加进去（gamma_atom 参数在日志里也写了“暂未显式引入”）。

这会带来两个很现实的风险：

- 波包形状/发射时间分布：会被你人为的 γ(t) 门控强行塑形，而不是由“|e⟩ 的动力学 + 固有辐射通道”自然决定。
- 发射成功率与残余激发：你会得到一些“脉冲结束后仍残留激发但不再衰减”的非物理尾巴，进而影响 p_qubit_emit、p_source、以及后续纠缠质量/成功率的解释。

你需要在物理上做一个明确选择（两条路都可行，但不能混着用）：

路线 A（更直接、也更贴近你目前 4 能级显式模型）：

- 让腔到外耦合的衰减率 γ_cav,out 为常数（由 g、κ_ex、κ_in 决定），不要再乘 |Ω(t)|²；
- 同时把“腔内损耗 κ_in 对应的不可用光子通道”也加成一个额外 jump（会让原子衰减但光子不进入可干涉模式），再把自由空间 γ_atom 也作为额外 jump（或按实验实际合并到一个“非腔通道损耗”）。
  这和输入–输出理论里“每个耦合到外界的通道都有对应阻尼项与 √(rate) 的输入输出耦合”是一致的；多端口时总阻尼是各端口之和。

路线 B（如果你本来想做“有效 Raman 发射/有效耦合随控制脉冲变化”）：

- 直接采用“时间依赖 jump operator L(t) ∝ Ω(t)”的有效模型，但这时通常不再需要显式保留 |e⟩ 的真实布居动力学（或者需要在大失谐消元框架下重写 H_eff 与 L_eff），否则你等于把控制场既当作 Hamiltonian 泵浦又当作系统–浴耦合调制，容易双重计数。关于消元得到有效 Lindblad 的一般形式，至少要保证得到的是显式 Lindblad 结构而不是“拍脑袋门控”。 ([arXiv](https://arxiv.org/pdf/1603.04630?utm_source=chatgpt.com))

如果你的目标是“对实验指导意义”，我更建议路线 A：把物理通道拆开（外耦合、腔内损耗、自由空间散射），这样你才能分别对应实验里的可测/可标定参数（腔外耦合效率、Purcell/合作因子、分支比等），而不是把所有效率都塞进一个 η_mean。

一、为什么会出现“time-bin + 碰撞模型”的写法

1. 连续输出场在输入输出理论里是“连续的自由度”
   在 cavity/waveguide QED 的标准输入输出框架里，局域系统（原子/腔）耦合到一维行波场；输出场等于输入真空场加上系统辐射出来的那部分，形式上常写成 b_out(t) = S b_in(t) + L(t)（多端口/多通道时 S 是散射矩阵，L 是耦合算符向量）。([Cleland Lab](https://clelandlab.uchicago.edu/pdf/cook_PhysRevA_98_013801.pdf))
   这句话的意义是：你只要给定“系统内部哈密顿量 H_sys(t)”和“耦合/跃迁算符 L_μ(t)”（μ 标记通道/偏振/端口），整个辐射-散射过程就被完整决定。
2. time-bin 离散化 = 把连续场切成一段段独立的小模式
   为了用 MPS/TEBD 数值模拟，你把连续场按时间步长 Δt 切成 N 段：每段对应一个“时间仓 time bin”，每个 time bin 是一个有限维的玻色模式（你这里做了单光子截断：vac, H, V…）。这种“把连续模式离散化到 time-discrete picture”是 waveguide/cavity QED 用 MPS 做数值的常见路径。([Inspire](https://inspirehep.net/files/ca191a3156bc35eb0ffaf2c5cc1fcd74))

直观图像就是：系统每个时间步只跟“当前这一小段真空浴”短暂相互作用一次，然后这段浴就作为输出的一部分离开；下一个时间步换下一段真空浴来碰撞（collision）。这也是很多文章把它直接称为“collisional picture / collision model”。([Inspire](https://inspirehep.net/files/ca191a3156bc35eb0ffaf2c5cc1fcd74))

1. MPS/TEBD 的“时序交互”实现方式
   在 time-bin MPS 里，你每一步只需要对“系统位点 + 当前 time bin 位点”施加一个局部门（MPO 的局部块），然后把系统位点 swap 到下一个 time bin 前面（或把 time bin swap 过去），重复 N 次。Regidor 等人的实现说明里就明确描述了：时间演化算符在“系统 bin 与对应 time bin”上局部作用，并用 swap 把系统移动到下一步位置。([Inspire](https://inspirehep.net/files/ca191a3156bc35eb0ffaf2c5cc1fcd74))
   Pichler & Zoller 也明确说他们用 MPS 去解量子随机薛定谔方程（QSSE），把系统与“发射光子流”的纠缠高效编码进 MPS。([arXiv](https://arxiv.org/abs/1510.04646))

- 条件在“确实发射出一个可用光子”时的时域模式离散系数 f_n（n=0…N-1），满足 Σ|f_n|^2=1，
- 以及相位轮廓 φ_n（若你要包含 chirp/频偏/相位参考），最终模式为 f_n·e^{iφ_n}。

1. 把目标强度分布转成每个 bin 的“目标发射概率”
   w_n = p_emit · |f_n|^2。
   这里 w_n 是“光子落在第 n 个 bin 的概率”，因此 Σ w_n = p_emit。
2. 用一个严格的离散公式，把 w_n 反推为你 `emission_gate` 需要的 gamma_n
   关键点：你 `emission_gate` 里有两个正交通道 H/V，每个通道的速率参数都叫 gamma，文档也写了“gamma 是单通道发射率（总发射率的一半）”。
   所以总耦合强度在单激发子空间里相当于 √(2·gamma_n)（直观上就是两个 Lindblad 通道的速率相加）。

定义 s_n 为“到第 n 个 bin 之前还没把那部分可发射激发释放出去”的剩余概率（离散 survival）：
s_0 = p_emit（如果你把“可发射分量”看作一开始就准备好了），
s_{n+1} = s_n − w_n。

在纯 collision、无额外 Hamiltonian 的情形下，一步门相当于在“激发态”与“本 bin 的输出光子子空间”之间做一次旋转。为了让“在第 n 个 bin 发射”的概率精确等于 w_n，你可以用：

sin^2( √(2·gamma_n·dt) ) = w_n / s_in( √(w_n/s_n) )]^2 / (2·dt)

dt 是 bin 宽度（秒）。这个公式有两个好处：

- dt 不需要极小也能比较稳（因为我用的是离散旋转的“精确版”，而不是小角度近似）。
- 你可以把任何形状（高斯、指数、对称截断指数、实验测得的 histogram 归一化结果）直接变成 gamma_n 序列。

如果你不想用 arcsin，也可以用小 dt 近似：gamma_n ≈ w_n / (2 s_n dt)，但我建议用上面的 arcsin 版更稳。

1. 你需要加一个“准备门”，把原子从 |u> 准备出可发射激发分量
   因为你现在如果把 H_sys 去掉（Ω=0），原子永远不会到 |e>，就永远不会发射。你现在 `run_dual_atom_emission` 的初态是两原子都在 |u>。
   所以在路线1里，你应该在发射循环之前，对 atomA 和 atomB 各加一个 4×4 的单体门，只在 {|u>,|e>} 子空间做旋转：
   |u> → √(1−p_emit)|u> + √(p_emit)|e>。
   这样，发射段就等效成：
   |u>⊗|vac…> → √(1−p_emit)|u>⊗|vac…> + √(p_emit)·(纠缠态 ⊗ 单光子波包)，
   而“单光子波包的 bin 分布”由你设计的 gamma_n 决定。
2. 相位/频偏怎么进来
   你 `emission_gate` 有一个 `phase` 参数，会把同一个相位因子乘到 L_H、L_V 上。
   所以你可以进去，从而生成一个带 chirp 的 e(t)。这点和 Morin 等强调的“相位是网络相干性的核心”是一致的。
